## 2. 根因

D9 的依据是食品安全法 71、73 条和广告法 17 条：食品不得声称疾病预防、治疗功能。EFFICACY_RE 经 P16a / P24a / P29a / P31a 几轮扩充，已经按语义收了「降 / 控 / 稳 + 血糖类指标」「时段 + 方向谓词」「波动平滑化」「回归谓词」「停药挂钩」「器官修复」几类说法，但同一类功效主张还有三种说法没收：

1. **动词直接作用于「糖」**。「克糖」里的「糖」就是血糖，单字「糖」不在主语类里，现有分支要求出现「血糖 / 糖化 / 胰岛 / HbA1c」。
2. **器官负担减轻**。「让胰腺歇一歇」暗示吃了能减轻胰腺负担、保护胰岛功能，和禁用词「修复胰腺」同属器官功能声称。P31a ③ 只收了「恢复 / 修复 / 再生 / 激活」这类修复谓词，没收「歇 / 减负 / 负担变小」这类减负谓词。
3. **用测量读数代替血糖作主语**。控糖人群说的「扎出来的数」「测出来的数」「指血」「读数」指的就是血糖值，配上「变小 / 变低 / 降 / 好看」就是血糖结果承诺。现有主语类只认血糖类词和时段词。

## 3. 根因修 P61a（proposal 115）

在 EFFICACY_RE 上追加三支，按语义类写，不针对单句补词：

- `_GLY_ACT_ON_SUGAR`：「克 / 抗 / 降 / 消 / 压 / 治」紧接单字「糖」，用否定先行断言排除名词性搭配：糖尿病、糖果、糖水、糖分、糖浆、降糖药、糖类、糖醋、糖精、糖块、抗糖化。所以「代替不了降糖药」这类否定句不会命中。
- `_ORGAN_RELIEF`：「胰岛 / 胰腺 / β 细胞」配「歇 / 休息 / 喘口气 / 减负 / 轻松」，「负担 / 压力 + 变小 / 变轻」，或「减轻 / 分担 …（胰岛）负担」。
- `_READING_SUBJ` + `_READING_DOWN`：主语是「扎 / 测 / 量出来的数（数字 / 数值）」「指尖血 / 指血 / 读数 / 血糖仪上的数」，谓词是「变小 / 变低 / 少一圈 / 降 / 下来 / 好看」。

补丁 `P61a.patch` 共 35 行，只改 `_fde.py`。
