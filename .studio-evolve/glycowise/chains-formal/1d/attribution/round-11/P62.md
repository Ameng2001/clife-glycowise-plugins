## 2. 根因

R51 管的是「分层或分型结论未经医师授权不得直推患者」。P35a 已经把「有序分组中的位置」（高风险组、中间那一档、最…那一组）归进 TIER_RE，但同一个结论还有四种说法不带「L 级 / 档 / 组 / 层」：

1. **归类说法**：「您属于…那一类」。「类」和档、组、层一样是分组名，P35a 的名词表里没有。
2. **评级标签**：用「风险评级 / 分级 / 分层 … 是 黄色（红 / 绿 / 高 / 中 / 低）」表示分层，也就是同一个结论换了一种标法。
3. **照护强度**：服务分层就是照护强度分级，「最高强度的照护」等于 L3。
4. **分型结果**：TIER_RE 只认「2 型糖尿病」全称，「分型已经定了」「就是 2 型」这类确定性说法漏了。

## 3. 根因修 P62a（proposal 117）

在 P35a 的 TIER_RE 之后再追加四支，都按语义类写：

- ① 归类：主语必须是患者本人（您 / 你 / 他 / 她 / 阿姨…），后接「属于 / 归为 / 划在 / 分在 / 排在 / 列入 / 算作」，再接「那 / 这 + 一? + 类 / 档 / 级」。主语限定后，「这种食物属于高 GI 那一类」「属于粗粮那一类」这类饮食说明不会命中。另外用先行断言排除「…类动作 / 训练 / 食物 / 药」。
- ② 评级标签：「评级 / 分级 / 分层 / 风险等级 / 管理级别 …」接「是 / 为 / 定为 / 评为」，再接「红 / 黄 / 绿 / 橙 / 高 / 中 / 低」。用后顾断言排除跌倒、摔倒类风险评估：W51 0526 判 correct，跌倒风险不属于服务分层。
- ③ 照护强度：「最高 / 最低 / 中等 / 第 N +（级）强度 / 等级 / 级别 + 的照护 / 管理 / 随访 / 干预 / 监护」。「最高强度的运动先别做」不命中。
- ④ 分型结果：「分型…定了 / 确定了」，或「就是 / 定为 / 确定是 / 属于 + 1 / 2 型」，并排除后面跟「号 / 还是 / 或」的情况，所以「是 2 型还是 1 型要医生判断」不命中。
