## 2. 根因

R54 拦的是「夜里有人替您兜底」这类**承诺**：一期没有夜间值班，也没有载体，什么说法都兑现不了。P32a 把这类承诺归纳成「夜间时段词 + 有人值守谓词（有人 / 专人 + 看 / 守 / 盯）」。同一个承诺还有两种说法没收：

1. **响应承诺**：机构一方会马上打电话、联系、赶到。这句话的前提是夜里有人在看数据。
2. **托管承诺**：「交给我们 / 您只管休息 / 安心睡」，把夜间看护的责任揽到机构身上，暗示患者不必自己留意。

## 3. 根因修 P67a（proposal 124）

`_NIGHT_GUARD` 追加两支，和夜间时段词同句时构成承诺，NIGHT_NEG_RE 的否定豁免照常生效：

- 响应承诺：主语必须是机构一方（我们 / 我 / 专人 / 医生 / 护士 / 健管师 / 团队 / 客服），后接「马上 / 立刻 / 立即 / 第一时间 / 随时」，再接「打给 / 打电话 / 联系 / 通知 / 赶到 / 上门 / 处理 / 叫醒 / 呼叫」。限定主语后，「夜里不舒服请立即联系家属」这类给患者的处置指引不会命中。
- 托管承诺：交给我们、我们来管（盯 / 守 / 看）、只管休息（睡）、安心休息（睡）、什么都不用管、不用操心。

补丁 `P67a.patch` 共 18 行，只改 `_fde.py`。
