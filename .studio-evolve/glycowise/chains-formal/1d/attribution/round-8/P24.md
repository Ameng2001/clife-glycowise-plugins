## 2. 定位

`_fde.py` 的 `d9 = _product_gate or _efficacy_claim`。`_efficacy_claim` 在 生成产品推荐 上对 pitch 的每一句跑 `EFFICACY_RE`，h_s 里的式子是：

```
(降|控|稳|调节|改善|逆转|治|根治)…(血糖|糖化|胰岛|HbA1c|并发症) | (血糖|糖化)…(稳得住|稳住|降|正常|达标|不升) | 疗程 | 坚持(吃|用|服)…(个月|周|天)
```

它只收「降低方向的动词 + 血糖」和「血糖 + 少数几个结果词」，漏了 D9 依据法条下同一语义的两类：

1. **作用声称不分方向、不限主语字样**：「不往上冲 / 不冲高」（防止升高）和「降」是同一个功效主张；控糖话术里「餐后 / 饭后 / 空腹」指的就是该时段的血糖。
2. **疗效 / 起效用语本身**：「见效 / 效果更好 / 一周就能看到」。广告法第 17 条禁止非医疗广告涉及疾病治疗功能、使用医疗用语；食品安全法第 71、73 条禁止食品标签、广告涉及疾病预防、治疗功能。在控糖人群的食品推荐里，这类词不点名指标也是功效声称。

IR（ontology-map §D9）的 check 列只写了「与分层或缓解同句」，但规则名是「产品功效声称拦截」，依据是上述法条；P16a 已经按规则名把功效声称补进实现。本轮缺陷是 P16a 那份词表的覆盖面不够，属规则层。

## 3. 根因修 P24a（proposal 32）

按上面两类语义改写 `EFFICACY_RE`，不按 Dᵢ 句子逐个补：

- 指标主语（血糖 / 糖化 / HbA1c / 胰岛）配作用谓词，作用谓词不分方向：降、达标、不升、不涨、不冲、不往上、不飙、冲高、飙升、稳住、控制住、管住、压住，以及原来就有的正常、波动小；
- 时段主语（餐后 / 饭后 / 空腹）只配方向性谓词（不收「正常」，避免「饭后正常饮用」这类用法说明被误拦）；
- 疗效 / 起效用语：见效、起效、疗效、功效、效果（更好 / 好 / 明显 / 显著 / 立竿见影），以及「N 天 / 周 / 个月 … 就能看到 / 见到 / 有变化」；
- 原有的「降 / 控 / 稳 … 血糖」「疗程」「坚持吃 N 个月」照留。

补丁：`P24a.patch`，28 行（+18 −1），只改 `_fde.py`。

## 4. 朴素修：五条机械规则逐条判断

| # | 机械规则 | 适用？ | 理由 |
|---|---|---|---|
| 1 | 放宽阈值 | 不适用 | D9 没有数值阈值；唯一可调的量是 `[^。；，,]{0,6}` 的间隔窗，放宽它不能让 Dᵢ 命中（「不往上冲」「不冲高」「见效」「效果更好」都不在现有谓词表里，窗多宽都一样）。另外这是漏拦缺陷，「放宽」只会更松，方向就不对。 |
| 2 | 跳过缺参数的校验 | 不适用 | 这是漏拦（期望拒、实际放），跳过校验只会放得更多，不可能让 D9 响；Dᵢ 的参数（patient_id / sku_id / pitch）也都齐全。 |
| 3 | 删掉命中的规则分支 | 不适用 | Dᵢ 上 D9 没有任何分支命中（是没响，不是误响），没有「命中的分支」可删；删掉「放行」兜底不是删命中分支，而且会让 D9 对所有推荐都拒（r08 / r17 / 出口签发闸-05 这类中性推荐全挂）。 |
| 4 | hard 改 soft | 不适用 | D9 已是 hard；改 soft 只会把拒变成放，与期望相反。 |
| 5 | 把 Dᵢ 命中的字面量加进匹配 | **适用 → P24b1** | 把 4 条 pitch 里的「血糖不往上冲 / 见效快 / 一周就能看到 / 效果更好 / 餐后不冲高」原样并进 `EFFICACY_RE`，Dᵢ 即全过。 |

### P24b1（proposal 33，朴素修·规则 5）

`EFFICACY_RE` 末尾追加 `|血糖不往上冲|见效快|一周就能看到|效果更好|餐后不冲高`。补丁：`P24b1.patch`，12 行（+2 −1）。
