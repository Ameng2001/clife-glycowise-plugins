- 链：3d · round 10 · 窗口 2026-W53 · 本体状态 h₁₀

## 1 缺陷

| 案例 | pitch | 期望 | h₁₀ |
|---|---|---|---|
| r74 | 它代替不了降糖药，血糖照原来的办法控制；他下周复诊。 | action(生成产品推荐) | rejected [D9] |
| r79 | 血糖偏高的时候先别冲，问问医生 | action(生成产品推荐) | rejected [D9] |

两条是食品话术提到血糖的正当用法：声明不替代药物、把控糖交回原方案、以血糖状态为条件的食用限制 + 就医建议。都没有效果承诺。

## 2 定位

探针确认两条都是被 P28a 的反向判定拦下的（`_glycemic_implied_claim`），其它四条正则都不中：

- r74 分句「血糖照原来的办法控制」：剔掉豁免片段后「血糖」还在 → 算暗示。另一分句「它代替不了降糖药」本来就不含指标。豁免表只认「不(能|可|得)?替代」，不认「代替不了」。
- r79 分句「血糖偏高的时候先别冲」：豁免表没有「条件限制」这一类；「问问医生」也不在「咨询医生」里。

P28a 当初给的理由是：提到血糖只有两种正当用途——提醒监测，或声明不替代药物 / 遵医嘱 / 就医。r74 / r79 说明这张表少了口语写法，也少了一类正当用途（以血糖为条件的食用限制）。

## 3 根因修 P43a（proposal 79）

按「正当用途」的语义补豁免表（仍按片段剔除，不整句放行）：

1. 不替代声明的口语写法：不能替代 / 代替 / 取代，以及「代替不了 / 替代不了 / 取代不了 / 顶替不了」；
2. 把控糖交回原有治疗：「血糖（照 / 按 / 还按 / 继续按）（原来 / 原先 / 以前 / 医生 / 医嘱）…」，整个片段连同主语「血糖」一起剔掉；
3. 以血糖状态为条件的食用限制：「血糖…（的时候 / 时 / 期间）…（先别 / 别 / 不要 / 暂停）（冲 / 喝 / 食用 / 饮用）」。限制动词只收本品的食用动作，不收「别吃药」，避免「血糖高时别吃药，喝这个」漏网；
4. 就医建议的口语写法：问问 / 问一下 / 请教 + 医生 / 医师 / 营养师。

补丁 `P43a.patch`：`_fde.py` +7 / −1。
