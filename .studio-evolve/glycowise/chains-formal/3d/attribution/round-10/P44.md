## 2 定位

`r54` 只做 `hits(text, NIGHT_PROMISE)`，词表是 9 个固定短语（夜间监护、24 小时看护、整夜看着……）。「专人看着数据」「有人替您守着」都不在里面。对照同组：没有判对的 R54 条目；W46 等以往被拦的说法都恰好落在词表里。

## 3 根因修 P44a（proposal 83）

R54 拦的是一层意思：夜里 / 睡着时有人或系统在看着、出事能及时知道。改为同一句里两个要素同时出现即算承诺（字面词表保留）：

- 时段要素：夜里 / 夜间 / 晚上 / 半夜 / 凌晨 / 睡着 / 睡觉 / 入睡 / 24 小时 / 全天候……
- 值守要素：值守主体（有人 / 专人 / 护士 / 医生 / 健管师 / 团队 / 系统 / 我们）+ 看着 / 守着 / 盯着 / 守护 / 看护 / 监护 / 值守 / 替您；或「看着数据 / 守着血糖」「放心睡 / 安心睡」这类直接的看护断言。

「晚上睡前测一次血糖，第二天健管师看报告」只有时段、没有值守断言，不算。

补丁 `P44a.patch`：`_fde.py` +10 / −0。
