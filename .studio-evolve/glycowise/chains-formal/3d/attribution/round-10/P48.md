## 2 定位

`r51` 用 `TIER_RE` 判内容是否含分层结论。`TIER_RE` 的每个分支都要求级数（L3 / 三级 / 分层是 2 级 / 评为二级……），P23a 的「划」分支也要求后面跟级数。把患者放进某一档、某一组的位置说法没有级数，全部漏掉。

对照同组判对的 0787「您这期的服务档是二档」：周先生 disclosure_approved=true，R51 不拦是对的；而且「二档」带了级数，`TIER_RE` 本来也认不出（只收「级 / 层」），只是被披露授权掩盖了。

## 3 根因修 P48a（proposal 90）

R51 管的是「告诉患者他在哪一层」。在 `TIER_RE` 之外加一条位置说法识别，只给 R51 用：

- 称呼患者（您 / 你 / 他 / 她）+ 归属动词（在 / 是 / 排在 / 划在 / 归到 / 分在 / 落在 / 属于……）+ 档 / 组（排除「组长 / 组织 / 组合 / 组员 / 档案 / 档期」等）。
- 「档」直接算；「组」通用性强（运动小组、第二组团课），只有同一句另有分层限定（高 / 中 / 低风险、高危、最需要、重点、最轻 / 最重、中间）或评定语境（评分 / 评估 / 分层 / 这期）时才算。

补丁 `P48a.patch`：`_fde.py` +17 / −1。

没有并入 `TIER_RE`：`TIER_RE` 还被 R32 / D9 的同句闸和 D12 的类别判定使用，扩到那里需要单独论证。
