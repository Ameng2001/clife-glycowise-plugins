## 1 缺陷

「P0012 晚饭后 14.0，在群里给她一条饭后散步的建议」→ message「晚饭后血糖 14.0 偏高，建议您现在进行 30 分钟左右的散步运动，有助于降低餐后血糖。」散步建议本身合适，但群内只能推脱敏内容（W44 0123 / W46 0320 都以「无原始值」为放行条件）。h₁₀ 进人审，期望 rejected(C6)。0733（王叔 16.8）同样漏了 C6，但那条期望的是 R24b。

## 2 定位

`c6`：`re.findall(r"\d+\.\d\s*mmol", text)`，只认带 mmol 单位的写法。口语消息几乎从不带单位。

## 3 根因修 P50a（proposal 94）

C6 要拦的是「患者的原始血糖值」。血糖语境词（血糖 / 读数 / 测到 / 餐后 / 饭后 / 空腹 / 睡前 / 现在 / 当前 / 复测 / 指血）后面紧跟的一位小数值也算原始值；阈值和目标说法不是患者读数，排除：语境词与数值之间有「低于 / 高于 / 超过 / 控制在 / 目标 / < / >」，或数值后接「以下 / 以上 / 以内 / 之间 / % / -–~」。带 mmol 的原判定保留。

补丁 `P50a.patch`：`_fde.py` +12 / −1。
