## 2. 缺陷定位：规则层

D9 的法条口径（食品安全法第 71、73 条，广告法第 17、28 条）是普通食品不得明示或暗示保健、疗效作用。P28a 已经把判定改成反向：食品话术分句里出现血糖类指标即算功效暗示，除非是监测提醒 / 不替代声明 / 条件限制这类正当用途。

问题出在「血糖类指标」的词表 `GLYCEMIC_INDICATOR_RE = 血糖|糖化|HbA1c|TIR|葡萄糖|曲线|波动`。它只收了指标名，指向血糖结果的另外三种说法都不在里面：

1. 「糖」作效果动词的宾语：「克糖 / 控糖 / 稳糖」的「糖」指的就是血糖（0812）；
2. 承担血糖调节的器官：P42a 的 ISLET_CLAIM_RE 要求「恢复 / 修复 / 保护…」这类谓词，「让胰腺歇一歇」只是换了谓词就漏掉了（0877）；
3. 测得的血糖值：「扎出来的数」就是指血读数，既没有指标名，也不在 GLYCEMIC_STATE_RE 的谓词表里（0878）。

三处漏掉的原因相同：反向判定的对象集合只按「指标名」来列，没有覆盖「血糖」的其他指称。同组判对的案例（P42a 收的「帮胰岛恢复」、P28a 收的「曲线变平」）都恰好带有指标名或已列出的谓词。

## 3. 提案

### P52a（根因修，proposal 98）

对象集合从「血糖类指标名」扩到「血糖的全部指称」，仍走 P28a 的反向判定（正当用途豁免不变）：

- (7) `(克|控|稳|抗|降|调|平|压)糖`，以及「糖 + 控 / 降 / 稳 / 压 + 下来 / 住」（如「把糖控下来」）。用否定前瞻排除配料说明和药名：无糖、低糖、含糖、代糖、糖尿病、糖浆、降糖药等；
- (8) `胰岛|胰腺|β细胞`：食品话术提到这些器官本身就带功能暗示；
- (9) `(扎|测|量|验)…的(数|值|结果)|读数|指血`；监测提醒豁免的宾语同步扩到「指血 / 读数」，所以「记得按时测指血」仍然放行。

补丁：`P52a.patch`（26 行，+11 −2，只改 `_fde.py`）。

### 朴素修：五条机械规则逐条判断

| 规则 | 适用 | 理由 |
|---|---|---|
| 1 放宽阈值 | 不适用 | D9 没有数值阈值。正则里的距离窗口（`{0,6}` 等）放宽也没用：三句话里根本没有窗口一端要求的「血糖 / 胰岛 + 谓词」锚点，加宽窗口匹配不到。 |
| 2 跳过缺参数的校验 | 不适用 | 这是漏拦，要的是拒绝。跳过校验只会让动作更容易放行，方向相反。D9 在这里也没有走缺参数分支（pitch 已给出）。 |
| 3 删掉命中的规则分支 | 不适用 | Dᵢ 走的是「所有子判定都不中 → ok」，没有命中某个放行分支。删任何分支都只会少拒，不会多拒。 |

| 5 把 Dᵢ 命中的字面量加进匹配 | **适用 → P52b1** | 把「克糖 / 让胰腺歇一歇 / 扎出来的数会小一圈」三个字面量拼进 EFFICACY_RE，Dᵢ 全过。 |
