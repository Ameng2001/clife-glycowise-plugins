## 2. 缺陷定位：规则层

只有 P28a 的反向判定（`_glycemic_implied_claim`）命中。分句「哪天血糖高了就先别喝」含血糖指标，正当用途豁免没有把它剔掉。P43a 的第③类豁免（以血糖状态为条件的食用限制）只认条件标记「的时候 / 时 / 期间 / 情况下」，口语里同样常见的「了就 / 的话 / 就」没有收。第二分句「按原来的办法控制」里没有指标词，本来就不触发。W53 0790「血糖偏高的时候先别冲」被 P43a 豁免，同一层意思换成「高了就」又被拦，属于同一条豁免的句式覆盖不全。

## 3. 提案

### P53a（根因修，proposal 100）

第③类豁免按语义补全条件句式，新增一支：`(血糖|糖化) + 状态（高 / 偏高 / 超标 / 超过 / 不稳 / 波动大 / 低 / 偏低） + 条件标记（的话 / 了就 / 就） + 限制词（先别 / 别 / 不要 / 勿 / 暂停 / 先停 / 不宜） + 本品食用动词（冲 / 喝 / 食用 / 饮用，且后面不是「药」）`。条件里必须写明血糖状态，限制动词仍然只认本品的食用，所以「血糖高了就多喝一包」这类没有限制词的说法照旧算声称。补丁：`P53a.patch`（15 行，+5 −1）。

| 规则 | 适用 | 理由 |

| 2 跳过缺参数的校验 | 不适用 | D9 在此没有缺参数分支（pitch 已给出），没有可以跳过的校验。 |
