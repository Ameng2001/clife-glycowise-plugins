## 2. 缺陷定位：规则层

IR 中 R51 的条件是 `not includes_tier_label or disclosure_approved is True`。includes_tier_label 由文本推断：先看 TIER_RE（级数、L0–L4、「2 型糖尿病」全称、「评为 N 级」），再看 P48a 的 `_tier_placement`（称呼患者 + 归属动词 + 档 / 组）。R51 要拦的是「把患者在分层 / 分型结论里的位置告诉患者」这层意思，但实现只认少数几种名目：

- 「那一类」：P48a 收了「档 / 组」，没收「类」（0813）；
- 颜色等级：「风险评级是黄色」，红 / 黄 / 绿是分层的另一种标法（0839）；
- 照护强度的序位：服务分层就是照护强度分级，「最高强度的照护」说的就是 L3（0852）；
- 分型定论省掉「糖尿病」：「就是 2 型」不匹配 TIER_RE 的全称（0860）。

同窗 0869「管理强度定在第一档」带「档」，被拦对了，对照可见缺口在名目覆盖上，判定结构本身没有问题。

## 3. 提案

### P54a（根因修，proposal 104）

includes_tier_label 按「位置结论」的语义补全四种说出口的方式，都放进 `_tier_placement`：

1. `TIER_PLACEMENT_RE` 的名目加「类」，与「组」一样需要分层限定或评定语境才算（限定词表补「评级」）；否定前瞻加「型 / 似 / 药 / 食」，避免把「类型 / 类似 / 这类药 / 这类食物」当成分层；
2. `TIER_COLOR_RE`：评级 / 风险 / 等级 / 分级 / 分层 / 级别与红 / 橙 / 黄 / 绿（色 / 灯 / 档 / 级）同句；
3. `CARE_RANK_RE`：（最高 / 最低 / 最强 / 最重 / 最轻 / 第 N）+（强度 / 级别…）+（照护 / 管理 / 随访 / 干预 / 关注），并要求同句有称呼患者和评定语境（评估 / 评分 / 分层 / 结果 / 需要 / 属于）；
4. `TYPE_VERDICT_RE`：（就是 / 属于 / 确定是 / 定为 / 判为 / 分型是）+ 1 / 2 型（后面不是「号 / 传感器 / 试纸」）。

补丁：`P54a.patch`（35 行，+17 −2）。
