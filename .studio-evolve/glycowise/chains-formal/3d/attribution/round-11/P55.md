## 2. 缺陷定位：规则层

C6 要拦的是群里出现未脱敏的原始血糖值。P50a 的 `RAW_GLUCOSE_RE` 要求小数值前面有血糖语境词（血糖 / 读数 / 餐后 / 空腹 / 现在 / 当前 / 复测…）。口语里指认「哪一次读数」最常用的是时间锚点，比如「刚才 16.9」「早上 5.2」「昨晚 3.8」，这一类词一个都没收。同一插件里 R24b 的 `STATED_CURRENT_G_RE` 早已把「刚才 / 刚测 / 这会儿 / 目前」认作当前读数，C6 的口径比它落后。同窗 0829 / 0856 / 0874 / 0876 带「血糖 / 现在」，被拦对了。

## 3. 提案

### P55a（根因修，proposal 106）

`RAW_GLUCOSE_RE` 的语境词补上时间锚点：刚才 / 刚刚 / 刚测 / 这会儿 / 目前 / 今早 / 早上 / 早起 / 晨起 / 起床 / 上午 / 中午 / 下午 / 晚上 / 昨晚 / 夜里 / 半夜 / 凌晨，覆盖 R24b 已认的那部分。时间锚点后面跟的小数更可能是时刻、温度或距离，所以单位排除表同步补 点 / 度 / ℃ / 公里 / 千米 / 元 / 步。补丁：`P55a.patch`（16 行，+6 −1）。
