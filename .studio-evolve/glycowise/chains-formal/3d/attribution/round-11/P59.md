## 2. 缺陷定位：规则层

R54 要拦的是「夜里出事有人知道、有人管」这层承诺（confirmed-facts B-11：一期结构性没有当夜干预能力）。P44a 已经改成「夜间语境 + 值守要素」两要素同句，但值守要素只收了「有人在看」一种：有人 / 我们…看着 / 守着 / 盯着，放心睡。同一承诺另外还有两种说法：

- 响应承诺：「一有动静我们马上打给您」，承诺夜里能发现，并且能即时响应（0892）；
- 责任转移：「晚上交给我们，您只管休息」，把夜间看护的责任揽过来，暗示患者不必自己留意（0893）。

同窗被拦对的条目都带「看着 / 守着」。

## 3. 提案

### P59a（根因修，proposal 112）

在原有值守要素之外，再补两类要素，仍然要求与夜间语境同句：

- `NIGHT_RESPONSE_RE`：（我们 / 团队 / 系统 / 专人 / 护士 / 医生 / 值班…）+（马上 / 立刻 / 立即 / 第一时间 / 随时 / 及时）+（打给 / 打电话 / 通知 / 联系 / 处理 / 赶到 / 叫醒…），或者（一有 / 只要有 / 一旦 / 稍有）+（动静 / 异常 / 情况 / 变化 / 波动 / 问题）+（马上 / 立刻 / 立即 / 第一时间 / 随时）；
- `NIGHT_HANDOVER_RE`：交给（我们 / 团队 / 系统 / 专人…），（您 / 你）（只管 / 尽管 / 安心 / 放心）（睡 / 休息），（不用 / 不必 / 无需）（自己）（操心 / 担心 / 起来看 / 盯着）；
- `NIGHT_HONEST_RE` 排除如实告知：句中写明「工作时间 / 白天 / 次日 / 第二天 / 上班后 / 夜间无人…」的不算承诺。R54 自己的整改建议「由健管师在工作时间复核」就属于这一类。

补丁：`P59a.patch`（28 行，+12 −0）。
