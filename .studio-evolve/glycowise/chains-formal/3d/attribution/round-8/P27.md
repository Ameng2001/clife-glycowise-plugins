## 2. 定位

`_efficacy_claim` 会扫描产品话术句（含产品名，或本次是 pitch），用 `EFFICACY_RE` 判断是否构成功效声称。这条正则只认两种形态：「降 / 控 / 稳 / 调节 / 改善 … + 血糖 / 糖化 / 胰岛 / HbA1c / 并发症」和「血糖 / 糖化 + 稳住 / 降 / 正常 / 达标 / 不升」，另外再加上疗程和「坚持吃 N 个月」。

D9 的依据是食品安全法第 71、73 条和广告法第 17、28 条：普通食品（固体饮料）不得明示或暗示具有保健、疗效作用。Dᵢ 是同一种声称的另外三种说法：

1. **血糖走向承诺**：「饭后血糖不往上冲」「餐后不冲高」。在控糖语境里，「餐后 / 饭后」指的就是餐后血糖；「不冲」「冲高」不在谓词表里。
2. **疗效断言**：「见效快」「效果更好」。食品没有可以宣称的「效果」，向控糖人群说「效果」，意思就是控糖效果（业务侧注明与 W50 0416 / 0433「配合吃效果更好」同一口径）。
3. **起效时间承诺**：「一周就能看到」。

对照同组判对的案例：产品与机构合规-r42（W51，「坚持三个月，糖化能降下来」）、r26（「糖化能再降一截」）、r27（「坚持吃三个月血糖稳得住」）都落在现有两种形态里，所以拦住了。中性话术（r08 / r17 / 出口签发闸-05，「作为日常饮食的补充」）放行，这是对的。

## 3. 提案

### P27a · 根因修（proposal 42）

在 `EFFICACY_RE` 之外，按 D9 的法条语义补上三类表达形态，入口与 EFFICACY_RE 相同（只在产品话术句里判）：

- `GLYCEMIC_OUTCOME_RE`：（血糖 / 糖化 / 餐后 / 饭后）+ 8 字以内 +（不冲 / 不升 / 不涨 / 不高 / 冲高 / 平稳 / 稳定 / 下降 / 降下来 / 压住 / 控制住）
- `EFFECT_CLAIM_RE`：见效 / 起效 / 疗效 / 功效 / 奏效，或「效果」+ 2 字以内的程度或比较词（更 / 很 / 明显 / 显著 / 好 / 佳 / 快）
- `ONSET_CLAIM_RE`：（数字 / 中文数字）+（天 / 周 / 个月）+ 6 字以内 +（见效 / 起效 / 看到 / 看出 / 改善 / 降）

已核对固定尾注：「固体饮料，不替代药物」「本内容为健康管理建议，非诊疗行为」都不会被这三条命中。

- 补丁：`P27a.patch`（27 行，+10 / −1，只改 `_fde.py`）
- `patch -p1 --dry-run -d chains-formal/ancestor-s`：通过；`py_compile`：通过
- Dᵢ（`--state h_prime --as-of 2026-10-25`）：4/4 原题，12/12 行全部通过（reject · D9）。r43 / r44 / r45 的 setup 里有前序的同类推荐（即 r41–r44 的话术），在本状态下被拒，记为 `SETUP_DIVERGED`。这是候选本体对那几步历史的反事实改写，正常评判。

### 五条朴素规则 × 本缺陷

| 规则 | 适用？ | 提案 | 理由 |
|---|---|---|---|
| 放宽阈值 | 不适用 | — | D9 没有数值阈值。唯一接近阈值的是 EFFICACY_RE 的 `{0,6}` 间隔窗，但 Dᵢ 的谓词（不往上冲 / 不冲高 / 见效 / 效果更好）根本不在谓词表里，间隔放到多宽都匹配不上；而且「放宽」只会减少拒绝，方向与本缺陷（漏拦）相反 |
| 跳过缺参数的校验 | 不适用 | — | Dᵢ 漏拦不是因为缺参数（patient_id / sku_id / pitch 都在），跳过校验只会减少拒绝 |
| 删掉命中的规则分支 | 不适用 | — | Dᵢ 一个分支都没命中（这正是缺陷所在），删分支只会减少拒绝，不能让 Dᵢ 被拒 |
| hard 改 soft | 不适用 | — | 改成 soft 只告警不阻断，而 Dᵢ 要求 rejected(D9)，soft 违规不会让 `would_commit` 变假 |
| 把 Dᵢ 命中的字面量加进匹配 | 适用 | P27b1（proposal 43） | 把 Dᵢ 的字面量「不往上冲」「见效快」「效果更好」「不冲高」加进 EFFICACY_RE 的候选项，4 条全部被拒 |

### P27b1 · 朴素修，把 Dᵢ 命中的字面量加进匹配（proposal 43）
在 `EFFICACY_RE` 末尾追加 `|不往上冲|见效快|效果更好|不冲高`。
- 补丁：`P27b1.patch`（12 行，+2 / −1）；dry-run 通过；py_compile 通过；Dᵢ 12/12 行通过（SETUP_DIVERGED 同 P27a）
