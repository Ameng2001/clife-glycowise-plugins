## 0. 开口之前，先记住三件事

**第一，一期不看夜里。** 数据是第二天汇总后由健管师和医生看。任何形式的"我们夜里盯着""有事马上通知你"都不能说——这不是保守，是我们现在**确实没有**这个能力。说了就是虚假承诺，出事要担责。

**第二，不能提产品功效。** 门店在售的营养品是固体饮料，属普通食品。不得说降血糖、修复胰腺、调理胰岛、逆转糖尿病，不得称"医学营养治疗"。服务和产品**分开谈、分开签、分开收款**。

**第三，"逆转""治愈""停药"是禁用词。** 「缓解」只有医生在面诊时、按共识定义（停药三个月以上糖化低于 6.5%）才能说，销售现场不许用。

## 1. 一期到底卖什么（内部先对齐）

一句话：**把居家这两周真实发生了什么，变成医生手上能用的证据，再当面讲给你听。**

拆成四件患者能感知的事：

| 交付 | 患者的感受 | 内部对应 |
|---|---|---|
| 两周连续的血糖曲线，不是几个点 | "原来我半夜血糖是这样的" | CGM 数据自动入平台，替代口头汇报与手抄 |
| 一份医生看得懂、能据此调药的报告 | "医生把我晚上那个药减了半片" | 低血糖证据通道 → 次日减药审查 |
| 有人每天看、异常了会找你 | "小韦昨天给我打电话了" | 健管师工作台的分诊队列 |
| 结束时当面讲 30 分钟 | "我总算知道我该怎么吃了" | 结营解读 |

**最容易被讲丢的是第二件。** 很多老人的问题不是"降不下来"，是"降得太狠"——二十年病程、在打胰岛素、糖化 7.4%，按老年目标其实偏低了。这两周的数据第一个用途往往是**帮医生找到可以减药的证据**，而不是再加点什么。这句话对老人和子女都特别有说服力，因为它跟他们预期的"你们又要卖我东西"是相反的。

## 2. 服务包交付清单

### A 体验包 · 14 天

| 时点 | 患者拿到什么 | 谁做 |
|---|---|---|
| 到店当天 | 医生问诊、身高体重体成分、糖化检测 | 医师 + 健管师 |
| 到店当天 | 传感器**佩戴指导服务**（不说"给您植入/安装"） | 健管师 |
| 到店当天 | 一张**纸质**《这两周怎么做》：怎么同步、洗澡怎么办、痒了找谁、低血糖了怎么办（含 15-15 法则与葡萄糖片） | 健管师 |
| 到店当天 | 葡萄糖片一小盒 | 门店 |
| 第 1–13 天 | 每天一条企微日报（大字图片，回数字就行） | 系统 + 健管师审 |
| 第 2–3 天 | 一次主动回访：贴得舒不舒服、痒不痒 | 健管师 |
| 第 7 天 | 中期小结 + 预约结营时间 | 健管师 |
| 第 14–17 天 | **到店当面解读 30 分钟** + 纸质报告 | 医师 / 健管师 |

**CGM 一枚，全程单路。** 器械由持证方直接售予患者，门店只做引导与佩戴指导，不经手货款。

### B 标准包 · 90 天

在 A 包基础上增加：CGM 共 4 枚（首月 2 枚连续、之后每月 1 枚复查）、医师复诊 3 次（含用药调整）、营养师随访 12 次（前两周每日）、运动方案 2 次、心理 1 次、健管师每周复盘、首末两次糖化。

**定价 〔待定〕**。

### C 缓解包 · 180 天

在 B 包基础上：CGM 共 7 枚、医师 6 次（含减药与停药决策）、营养师 24 次、家属课堂 2 次、0/3/6 月三次糖化、C 肽与肝肾一次。

**入包前必须由医师做适宜性评估**（抗体、体重腰围、C 肽、病程四项），不满足不得入包。

**结果承诺的说法只有一种**：达到约定目标之一则赠三个月维持期，未达到也赠。**不得说"保证""一定""多少成功率"**——广告法禁止承诺有效率。

## 3. 分人群怎么开口

### 3.1 对老年患者本人（如 68 岁、病程二十年、在用胰岛素）

**开场，讲她关心的，不讲数据**

> "阿姨，您血糖这么多年了，最怕的是不是半夜心慌、出汗、腿软？
> 这个小东西贴在胳膊上两个星期，能把您每天的血糖连成一条线。
> 医生看了这条线，才知道您现在的药是不是**开重了**。"

**为什么这么开**：她要的是安心不是数据；而"药可能开重了"和她预期的"又要加药、又要卖我东西"相反，能建立信任。

**回答"疼不疼、麻不麻烦"**

> "贴的时候一下就好，比抽血轻。洗澡、睡觉都不用管它。
> 手机的事不用您操心，我教您女儿弄一次就行。"

**结营时怎么讲**（这 30 分钟决定她续不续）

> 顺序：先讲夜里 → 再讲白天 → 最后讲吃。
> "您这两周，夜里有两次血糖掉到 3 点几，您自己没感觉。
> 这个我已经写进报告给黄医生了，他看了说晚上那个药可以减半片。
> 白天大部分时候是稳的。吃的方面，只有一件事我想让您改……"

**只给一件事改**。老人记不住三件，给三件等于一件都不改。

**⚠ 对 65 岁以上禁用**：控制饮食、限食、节食、代餐、过午不食、管住嘴。「营养跟不上」不说「营养不良」，「腿没劲、肌肉流失」不说「肌少症」。**"控糖""达标"这些词的默认方向是"更少"，而对这个年纪的人，正确方向往往是"更多、更好"。**

### 3.2 对异地子女（代付与代决策）

**开场，直接回应她的无力感**

> "您不在身边，最难的是不知道爸妈到底怎么样——他们在电话里永远说'挺好的'。
> 这两周结束，您会拿到一份您**看得懂**的周报：白天几天有数据、夜里几天有数据、这一周有没有出过事、医生做了什么调整。"

**必须主动说清楚的一句（不说就是隐瞒）**

> "有件事我要跟您讲明白：我们**不会在夜里实时盯着**，也不会夜里打电话给您。
> 数据是第二天汇总后由健管师和医生看。
> 夜里如果出事，靠的是老人自己和身边的人。所以我要请您登记一个**本地能随时到场**的人——您在外地，物理上是救不了的。"

**为什么必须说**：这是一期的真实边界。不说清楚，她会按"有人在看着"的方式安排生活（比如不再让人陪住），这比没有服务更危险。而且主动讲边界反而建立信任——她会觉得这家机构不吹牛。

**她会问"那我花这个钱买什么"**

> "买三件事：第一，爸妈身上真实发生了什么，您第一次能看见；
> 第二，医生手上有了能据此调药的证据，不是凭一次门诊的印象；
> 第三，有个具体的人每天在看，异常了会找您爸妈。"

### 3.3 对中年在职患者（有数据素养、警惕被卖货）

**开场直给，别铺垫**

> "两周连续血糖，看你哪一餐、哪个时间段是问题。
> 结束时医生和营养师一起给你一份判断。
> 这两周我们不卖你任何食品。"

**最后那句要主动说。** 这类客户一嗅到卖货就整体不信任，先把这条摆出来反而降低戒备。

**他会问"和我自己网上买一个有什么区别"**

> "设备是一样的。区别在贴完之后：
> 自己买，你会拿到一堆曲线，然后不知道怎么办；
> 在我们这，医生和营养师看完给判断，两周后当面讲。
> 真实数据是，自己戴的人只有四成能完整戴完一个周期。"

## 4. 必答问题（每个人都会问）

**"夜里出事怎么办？"**
> "一期我们不做夜间实时监测，这个要说在前面。夜里靠您自己和身边的人，所以我们会给您葡萄糖片、教您 15-15 的处理方法、并且登记一个本地能到场的人。第二天数据上来，我们会看,有问题会联系您和医生。"

**"戴了能不能不吃药 / 能停药吗？"**
> "药的事只有医生能决定,我不能说,也不该说。我能做的是把这两周的数据整理清楚给医生,让他有依据判断。"
> **健管师到此为止,不得展开。**

**"这个能治好糖尿病吗？"**
> "它是一个测量的工具,不是药,不治病。它的价值是让您和医生看清楚状况。"
> **不得出现"逆转""治愈""控制住""调理好"。**

**"和你们卖的那个营养品比呢？"**
> "这是两件事,分开的。营养品要不要吃、吃什么,是医生在诊室里单独看、单独开的,跟这个服务包没关系,也不在一张单子上。"
> **不得把血糖情况和产品推荐连在一起说,一句都不行。**

**"两周会不会太短，看得出什么？"**
> "两周是国际上给的最少天数,少于这个出来的结论不作数。而且要求这两周里至少七成时间有数据——所以我会盯着您有没有按时同步。"

**"多少钱？"**
> 〔定价待定〕
> 说法上：先讲交付了什么、结营会拿到什么,再报价。**不要用"才多少钱""一天只要几块"这类话术**——对老人有效但会拉低信任,且这类话术是私域营销投诉的高频画像。

## 5. 红线对照表（打印贴在工作台）

| ❌ 不能说 | ✅ 改成 |
|---|---|
| 我们夜里盯着 / 有事马上通知您 | 数据第二天汇总后由健管师和医生看 |
| 逆转 / 治愈 / 根治 / 调理好 | （不提。医生面诊时按共识说"缓解"） |
| 能停药 / 减药 / 药可以不吃了 | 药由医生决定，我把数据整理给他 |
| 这个降血糖 / 修复胰腺 / 调理胰岛 | （产品一律不与血糖情况连说） |
| 医学营养治疗 / MNT 方案 / 疗程 | （不用。产品是食品，医生单独开） |
| 保证 / 一定 / 成功率 X% | 达到约定目标或未达到，都赠三个月维持期 |
| 给您植入 / 安装 | 佩戴指导 |
| 我们逆转中心 | 糖尿病（特色）门诊 |
| 控制饮食 / 限食 / 管住嘴（对 65+） | 吃够、吃好；先加蛋白 |
| 您这是中度糖尿病 | （分层是内部标签，不对患者说。由医生判断并告知） |
| 危急值 | 红色预警 / 紧急提醒 |

**遇到这四类问题，一律转医师，不要自己答**：用药加减停、诊断与分型、并发症、能不能怀孕/手术。

转的话术：
> "这个我不能给您答，我马上帮您约黄医生。"

## 6. 销售现场三条自查

签单前问自己：

1. **我有没有暗示过夜里有人看着？** 包括"我们一直在""随时能找到我们"这类模糊表述。
2. **产品和服务有没有在同一段话里出现过？** 有就是踩线。
3. **我说的每个效果，是不是都能拿数据兑现？** 说了"能看清哪一餐有问题",就要保证结营时真的讲了这一条。
