### 2.3 数据对接能力评估结论

1. **没有任何一家在华 CGM 厂商公开自助式开发者门户 / OAuth 数据授权 API**（雅培、硅基、三诺、微泰、鱼跃均未查到；标未证实，需商务询证）。B 端对接普遍是「项目制」：厂商院内系统 + 蓝牙网关 + 定制接口，或与大平台（京东健康、平安健康、微医）点对点集成。
2. 最现实的三条数据路径：
   - A. **厂商 B 端合作对接**（硅基 pm@sibionics.com、三诺 400-887-0036、微泰检棠）：需签约，可获得患者授权后的云端数据推送/拉取；周期不确定。
   - B. **第三方聚合层**（糖动）：一次对接多品牌，但增加一层数据合规责任与费用。
   - C. **患者侧分享/截图 + 人工/OCR**：各家 App 都有亲友分享（雅培 20 人、微泰小程序、三诺亲友端、硅基分享码），可让健管师作为「亲友」实时看数据，作为 API 之前的过渡方案。
3. 门店固定场景可加桂花网蓝牙网关做到店自动同步（需厂商配合协议）。

## 4. 「门店 + 居家」场景选型建议

评估维度：价格（患者自费）、可获得性（电商/门店）、B 端 API 成熟度、患者接受度（品牌认知、App 易用）、与我方平台的契合（企微/小程序、AI 建议）。

### 首选 1：三诺爱看（i6 / i3）
- 价格最低（79-149 元/枚，15 天，日均约 5-10 元），对「90% 自费」的客群最友好；连锁药店与基层渗透强，三诺本身面向药店诊所与基层医疗。来源：https://zhuanlan.zhihu.com/p/1962181353568175043 ；https://www.sinocare.com/zh/newsinfo_1171.html
- B 端成熟度最高：有院内系统 + 蓝牙网关、医生 PC 端、AGP 报告、SinoGPT「开放接口」、与平安健康/京东健康的既有数据集成案例，证明其愿意且能够做数据对接。来源：https://www.sinocare.com/zh/newsinfo_985.html ；https://finance.sina.com.cn/jjxw/2026-07-20/doc-iniimuyc3056461.shtml
- 精度有第三方 iCGM 标准研究背书（MARD 9.4%）。来源：https://www.sinocare.com/zh/academicinfo_7.html
- 风险：i3 MARD 略高于硅基/欧态；开放接口需商务谈判。

### 首选 2：硅基动感（GS1 / 轻享 / GS3）
- 国产份额领先，患者认知度高（618 GMV 破亿），GS3 带 AI 解读与 iCGM 级精度，轻享分体式长期成本最低。来源：https://news.qq.com/rain/a/20240816A0847W00 ；https://www.jiemian.com/article/14077670.html
- 官网直接给出医院市场 / 零售市场 / 品牌合作邮箱与招商热线，B 端入口最清晰；有院外血糖管理方案、硅基医生、互联网医院。来源：https://www.sisensing.com/
- 已被桂花网网关、华为手表、糖动接入，说明协议可对接。
- 风险：无公开 API 文档；GS3 价格偏高（约 260-329 元）。

### 备选 3：微泰 AiDEX X
- 精度好（MARD 8.66%）、15 天、价格中等；检棠系统「院内外一体化 + HIS 对接 + 小程序分享」最贴近我方「健管师远程看数」流程。来源：https://www.microtechmd.com/cn/products/linx ；https://www.cn-healthcare.com/articlewm/20221201/content-1476499.html
- 风险：零售声量不如前两家；API 未公开。

### 不建议首批
- 雅培：价格 475 元、无 API、LibreLinkUp 禁止医护用途；适合作为高端客户「自带设备」场景，用 LibreView 机构账号看报告即可。
- Dexcom：大陆可得性未证实。
- 华为：无 CGM 产品，只能做「手表风险评估 + 第三方 CGM」的营销联动。

### 建议路径
1. 第一阶段（0-3 个月）：门店代销三诺 + 硅基；健管师以「亲友/医生端」身份接入患者 App 分享；平台先做截图/报告 OCR 或人工录入结构化；同时启动两家 B 端商务谈判（三诺 400-887-0036、硅基 pm@sibionics.com）。
2. 第二阶段：与一家签订数据合作，走厂商云端推送；评估糖动作为多品牌中间层。
3. 门店检测区可选桂花网蓝牙网关做到店自动同步。
