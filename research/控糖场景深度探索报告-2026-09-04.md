## 一、一页结论

1. **场景成立，但要换主角**。至心/德心的"五师共管 + 糖尿病逆转"业务已经跑通线下，缺的是居家数据。CGM（持续葡萄糖监测）能把"患者口头汇报 7 点指血、健管师手抄飞书表"换成自动采集，这是本次探索的核心价值点。但 CGM 本身是钩子不是产品：国产 CGM 已跌到 60–150 元/枚，硬件无利润，国外纯 CGM 订阅公司（Levels、Zoe、Veri）2023–2025 全部收缩，活下来的（Virta、Twin、Omada）都把 CGM 当 14–30 天的诊断/教育工具，靠"医生 + 教练 + 可量化疗效"收年费。
2. **数据对接没有捷径**。雅培、硅基动感、三诺、微泰、鱼跃在华均无公开自助 API，B 端对接全是项目制商务谈判。首选三诺（最便宜、B 端最成熟、已与平安/京东健康做过数据整合）和硅基动感（份额第一、合作入口最清晰）。商务谈判是整个项目的最长路径，必须现在就启动。Phase 0 只能靠"截图/AGP 报告上传 + 多模态解析"和"指血仪标准蓝牙"兜底。
3. **合规是最大风险，且当前做法已经踩线**。三条红线：(a) CGM 是三类医疗器械，门店和平台都不能无证销售；(b) 英纽林系列是固体饮料，德心的"血糖分级 → 产品组合表"本身就是违法话术，同类案例已有刑事立案和百万级罚没；(c) 卫健委明令严禁 AI 自动生成处方，智能体不能按分级自动出"疗程方案"。"糖尿病逆转中心"这个名字与 2020/2025 两份卫健委名称规范冲突。
4. **临床规则库可以直接落地**。国际 ATTD 共识与中国 2021/2024 指南口径一致，已整理出 32 条可计算规则（低血糖优先、数据充分性门槛、老年三分层、餐后响应分析、缓解判定）。德心的四级指血分级可映射为 CGM 服务分层，但只能作内部标签，不能对患者说成诊断。
5. **建议的商业形态**：服务与产品物理分离。服务包三档（14 天体验 299–399 元 / 90 天标准 2,980–3,980 元 / 180 天缓解 9,800–12,800 元含结果承诺），CGM 成本占比 30% / 12% / 6%；英纽林作为医生方案下的独立 SKU，不进服务包合同、不进 AI 推荐、不进宣传。

## 二、内部材料告诉我们什么

### 2.1 现有业务闭环（德心柳州店，2026-07 实地）

```
前台分诊 → 医生问诊（HIS 建档）→ 健管师带检（一体机 + 体成分）→ 可选指血
→ 回诊室按 MNT 分级表推荐英纽林（7 天试用）→ 购买后纸质方案本 + 飞书表格建档
→ 专属企微群（医生 + 健管师 + 店长 + 专家）→ 群内发运动/膳食指引
→ 患者口头汇报 7 点指血 → 健管师手抄、人工判读、给饮食建议 → 周/月复盘 → 典型案例发朋友圈
```

真实痛点（来自跟踪表截图）：患者外出就不测；数据靠口头；健管师凭经验给"睡前低于 5.0 吃黄瓜"这类建议；复购依赖产品而非服务。

### 2.2 至心的诉求（2026-07-13 会议）

- 五师共管 + AI 健管师，糖尿病逆转是明星业务，90% 自费，单店月营收 40–60 万，南宁 17 店全部盈利。
- 明确痛点第 2 条："居家服务缺少稳定数字化数据采集渠道，居家设备反馈数据量低"。
- 合作需求第 1 条：线下站点、居家用户数据接入数联大模型，输出个性化方案。

### 2.3 产品规划已有的承接点（0907 PPT）

- 四层架构、8 个智能体（健康分析 / 行为分析 / 方案规划 / 方案生成 / 顾问专家 / 社群应答 / 服务自动分发 / 审核服务）。
- 数据采集页已列"智能血糖仪"，人群分型已列"糖尿病分型"，案例页已有"2 型糖尿病分型人群服务路径"。
- 服务场域：企微单聊 + 群聊（普通群 / 专项群 / VIP 群）+ 小程序服务商城；服务包配置→推荐→调整→执行→反馈闭环。

结论：产品规划的骨架能承接 CGM 场景，缺的是数据摄入层、指标计算层、临床规则库和合规闸门。

### 3.2 临床规则库（详见 sources/02）

- 核心目标值：成人 TIR>70%、TBR<3.9 <4%、TBR<3.0 <1%、CV≤36%；老年/高危 TIR>50%、TBR<1%、TAR>13.9 <10%。中国指南额外提示 CV>33% 即低血糖风险。
- 前置门槛：14 天佩戴 + ≥70% 有效数据，否则只做趋势描述。
- 规则优先级固定：低血糖 → 高血糖 → 波动。低血糖规则永远抢占。
- 德心四级分级可映射 CGM（晨间中位数 + 餐后 2h 75 分位 + GMI/TIR 辅助），但 CGM 不能用于诊断，只能作服务分层且需医生确认。
- 餐后响应（PPGR）算法可复现，但同人同餐日间 CV 约 30%，个性化饮食结论需重复 ≥2 次；跨品牌数据不可比。
- 德心"睡前 <5.0 吃黄瓜"应改为含 10–15 g 碳水的加餐。
- "缓解"硬定义：停药 ≥3 个月 HbA1c<6.5%（GMI 可替代）。DiRECT 2 年 36%、5 年 13%。Virta 的"逆转"允许保留二甲双胍，与"缓解"不可混用。英纽林固体饮料无任何缓解证据。
- 已整理 32 条规则候选表（R01–R32），含触发公式、动作、硬阻断/软提醒级别、依据来源。

### 3.3 商业模式（详见 sources/03）

- 国外：Virta 年化 $1.6 亿、逆转首年 $2,808、结果付费；Twin RCT 缓解率 71%；Omada 2025 IPO 转盈。共同点：人机结合、CGM 短期使用、靠 RCT 级疗效支撑高定价。
- 国内：无人公开"服务包价格 + 疗效"。唯一量化结果：平安控糖营 6 月达标率 57.3%（不用 CGM）、泰康燕园七师共管 + 微泰 CGM 高龄人群达标率 79.8%、40% 减药。省二医逆转中心 6 对 1 定价 3–4 万/疗程。
- 价格锚点：14 天 0–150 元（平台补贴）；1 月 500–3,000；3 月 3,600（浙二达标返还）至 3–4 万；6 月 9,000–18,000。患者对"血糖完全正常"WTP 中位 1,000 元/月，价格权重 62.7%。
- 老年人：有人工支持时依从性可以很高（老年病房 89% 坚持佩戴），障碍是看不清 App、不会贴、夜间报警。必须有子女端。
- GLP-1 普及制造"用药伴随 + 停药维持"两段需求，可作子包。

### 3.4 合规（详见 sources/04，22 条风险清单）

| 领域 | 结论 | 等级 |
|---|---|---|
| CGM 器械 | 三类医疗器械。门店"代销"无豁免；最现实是持证厂商/经销商直销，门店纯引流不碰货不收款；平台若上架须自取许可 + 网售备案 | 高 |
| 健康数据 | 血糖/用药属 PIPL 敏感个人信息：单独同意 + PIPIA + 境内存储；厂商云→平台需数据接收协议，记录留存 3 年；用血糖触发产品推荐要再单独同意。当前"企微群口头汇报 + 飞书手抄 + 店长同群"是最大现实风险面 | 高 |
| AI 建议 | 《互联网诊疗监管细则》第 21 条严禁 AI 自动生成处方。智能体可做数据解读、指南级生活方式建议、监测提醒、异常转介；分级/分型结论、用药、"疗程方案"必须医师/注册营养师签发后推送；需生成式 AI 备案 | 高 |
| 固体饮料 | 任何"降血糖/修复胰腺/逆转/MNT 医学营养治疗/疗程"表述违反食品安全法 71/73 条、广告法 17 条、总局 46 号公告。2025 年同类罚 10 万–122.9 万，另有刑事移送。朋友圈血糖对比案例同时触犯医疗广告办法第 7 条 + PIPL | 高 |
| 命名 | "糖尿病逆转中心"与卫健委 2020/2025 名称规范冲突，建议改"糖尿病（特色）门诊 / 代谢健康管理中心" | 中–高 |

### 3.5 技术方案（详见 sources/05，含架构图与时序图）

- 内部 schema 对齐 HL7 FHIR CGM IG v1.0.0（2025-09），字段借 Tidepool 三层时间 + Open mHealth 餐时枚举（正好覆盖 7 点指血语义）。统一存 mmol/L。
- 通道结论：小程序 BLE 直连 CGM 不可行（私有加密协议 + 小程序无后台）；指血仪走标准 Bluetooth Glucose Service 0x1808 可行；Phase 0 靠截图/PDF 多模态解析。
- 摄入层：幂等去重、传感器会话、校准点、佩戴率 <70% 不出指标。指标层 Python 自研，用 iglu 离线对拍（GPL 不嵌入）。
- 事件：低血糖 → 事件总线 → 企微群机器人（20 条/分钟限频，需去抖）→ 健管师；飞书多维表格 batch_create 做过渡同步。
- 人力：Phase 0 三人 4 周；Phase 1 五人 8 周；Phase 2 六人半 12 周。

## 四、目标场景设计

### 4.1 服务与产品分离后的新闭环

```
到店：分诊 → 医生问诊 → 一体机/体成分/HbA1c → 医生判定入组（缓解适宜性 ABCD 筛选）
     → 健管师佩戴 CGM（持证方开单收款）→ 患者授权数据接入（单独同意留痕）
居家：CGM 自动上云 → 平台摄入/指标/规则 → 低血糖告警直达健管师+患者
     → 社群应答智能体抽取餐食/运动打卡 → 餐后响应配对
     → 健康分析智能体出结构化结论 → 方案生成智能体出草稿 → 审核智能体过合规闸
     → 医师/营养师工作台签发 → 企微群推送日报/周报（脱敏卡片）
复盘：14 天 AGP 报告到店解读 → 五师复盘 → 服务包升级/续约
产品：医生在 HIS 内按营养方案单独开具，单独收款，不出现在服务包与 AI 输出中
```

### 4.2 三档服务包（推算，需用至心真实结果数据校准）

| | A 体验包 14 天 | B 标准包 90 天 | C 缓解包 180 天 |
|---|---|---|---|
| 人群 | 糖前期、新诊断、子女代付"第一次" | 已确诊用药者、GLP-1 用药者 | BMI≥27、病程 ≤5–10 年、C 肽正常 |
| CGM | 1 枚 | 4 枚（首月 2 枚连续 + 月度复查） | 7 枚（强化期 6 枚 + 缓解判定 1 枚） |
| 人工 | 医生 1、健管师 2 触点 | 医生 3、营养师 12、运动 2、心理 1 | 医生 6、营养师 24、运动 6、心理 2、家属课堂 2 |
| AI | 日报 + 餐后提醒 + AGP 自动报告 | 加餐食识别、异常实时推送、周报、方案草稿 | 加停药期预警、缓解判定 GMI 自动计算、家属周报 |
| 定价 | 299–399 元 | 2,980–3,980 元 | 9,800–12,800 元，未达缓解或减重 ≥10% 则赠 3 个月维持期 |
| 成本（推算） | ≈295 | ≈1,890 | ≈4,600 |
| KPI | 佩戴完成 ≥85%，A→B/C 转化 ≥30% | TIR +10pp，FPG 达标 ≥55%，续约 ≥40%，健管师人均管 ≥60 人 | 缓解率 ≥30%，减药 ≥50%，承诺触发 ≤35% |

健管师绩效按 KPI 计提，不按产品销售提成。

### 4.3 智能体话术边界

- 允许：事实呈现（"过去 7 天 TIR 68%，夜间有 3 次低于 3.9"）、引用指南的通用建议、监测/复诊提醒、危急值转介、已签发方案的执行提醒。
- 禁止：对个体下分级/分型结论、任何用药剂量/加减停、疗效承诺、由血糖分级自动映射产品。
- 设计：每条输出附固定尾注；首次弹窗单独确认"非互联网诊疗"；涉及方案变更的内容走审核智能体 → 医师签发；危急值走独立告警链路不经 LLM。
