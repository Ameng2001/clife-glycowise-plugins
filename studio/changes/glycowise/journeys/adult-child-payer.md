| 项 | 内容 |
|---|---|
| **Persona** | 李女士，37 岁，在深圳工作，母亲刘阿姨在柳州（T2D 20 年，多药 + 胰岛素）。微信重度用户、网购与线上问诊都熟，但**没有医学素养**，看到 TIR/GMI/CV 一片茫然。自己有小孩要带、有工作要交付 |

| **触发** | 二选一：① 过年/探亲回家，发现母亲血糖控制差（药盒乱、说"还行"但体重掉了、听邻居说她夜里头晕过）；② 收到父母的体检报告，HbA1c 或空腹血糖异常 |
| **结束态** | 她认为这笔钱值得——**续费 B 包、升级、或至少买维持包**，而不是"我们先停一停" |

| **她的角色定位（关键）** | **她是知情方与决策方，不是施救方。** 系统绝不能把临床判断或救援动作外包给一个在 900 公里外的人 |
| **触点白名单** | 微信/企微（外部联系人单聊）、小程序（子女端 · 付费与周报入口）、电话、门店线下（回柳州时）。**没有原生 App**；子女端不复制"店长也在患者群里"这个隐私错误 |
| **她拿不到什么** | **原始诊疗记录与用药明细**（PIPL 敏感个人信息，需老人单独同意且可撤回）。可见范围由老人或医师授权、留痕、可撤回 |
| **⚠ 前提变更（2026-09-04）：她的付费理由变了** | **硅基 CGM 接入已商务确认**（SDK / 蓝牙协议，实时原始读数）。此前"能不能及时知道爸妈夜里出事"只是一张饼——原 Phase 0 靠截图上传，**在物理上做不到夜间实时告警**。<br>→ **现在它是一条可交付的承诺**，因此可以、也应该被写进销售话术与合同。<br>→ 但承诺同时带来两个新义务：① 承诺什么就必须监控什么（**载体离线 = 承诺失效**，见 D2/D3）；② 一旦写进合同，"夜里没告警"就从"技术限制"变成**违约与法律风险**。<br>→ 一句话：**她买的东西从"每天一条安心报告"升级成了"夜里出事有人知道"，而后者的兑现门槛高得多。** |

## 3. 逐阶段明细

### 阶段 D0 · 发现不对劲（第 −14 ~ −7 天）

| 维度 | 内容 |
|---|---|
| **Actions** | 回家过年，看到药盒里有药没吃完/重复；发现母亲瘦了；饭桌上母亲说"还行你别操心"；私下问邻居才知道她上个月头晕过一次；或收到体检报告，看到几个箭头 |
| **Touchpoints** | 家庭线下、微信语音/视频、家庭群（转发养生文章，没有真实数据） |
| **Thoughts** | "她肯定报喜不报忧""我不在身边，万一夜里出事怎么办""钱我能出，我出不起的是时间" |
| **Emotion** | 😟 → 😰 焦虑上升，且**无处安放** |
| **Pain points** | ① 信息永远是二手且被美化的——问"血糖多少"答"还行"，实际漏测了五天；② 她**没有任何客观信号源**，只能靠追问；③ 内疚：不能在身边这件事本身是持续的心理成本 |
| **这一段告诉我们什么** | 她的购买动机不是"改善血糖指标"，是**"我需要一个能替我看着的人"**。所有获客素材如果讲 TIR 讲逆转，就讲错了对象 |

### 阶段 D1 · 查、比、怕被骗（第 −7 ~ −1 天）

| 维度 | 内容 |
|---|---|
| **Actions** | 搜"柳州 糖尿病 逆转 是不是骗局"；看门店朋友圈的"逆转案例"；问同事"我给我爸买了…"；比价（电商 CGM 一枚 60–150 元 vs 门店服务包 299–399 元）；犹豫要不要跟兄弟姐妹商量 |
| **Touchpoints** | 微信（门店企微名片、朋友圈）、小程序/网页（服务包介绍）、口碑（同事、大众点评） |
| **Thoughts** | "这个是不是智商税？我先查一下""299 买 14 天，比京东上贵，贵在哪""'逆转'这词一听就不靠谱" |
| **Emotion** | 😐 → 🤨 警惕 |
| **Pain points** | ① 门店现有物料上的"逆转/治愈/停药"话术**对她是反向信号**——她的第一反应是搜"骗局"；② 她比不出"服务"和"设备"的区别，因为我们没讲清楚；③ 价格相对重要性 62.7%，但对"医生背书/指南推荐"这类附加特性 WTP 仅 17.6–18.5 元——**堆资质无效，讲清楚"我们替你做什么"才有效** |
| **必须的产品动作** | **全渠道禁用"逆转/治愈/停药"**（招牌、物料、企微名片、朋友圈、AI 输出）。A 包的价值主张对她应表述为：**"14 天里我们替你看着，结束时我们当面告诉你三件事和三个下一步"** —— 卖的是那 46 个百分点的人工支持（自助 42.7% vs 人工支持 89–92%），不是设备 |

### 阶段 D2 · 付钱与开通（第 0 天）

| 维度 | 内容 |
|---|---|
| **Actions** | 小程序下单 A 包礼品版 399 元（含到店/上门佩戴指导）；陪母亲到店或远程遥控；开通**子女端账号**（独立身份、独立权限）；**在系统里登记 1–2 名本地可到场施救者 + 门牌地址**（老伴、邻居、社区网格员、物业）；跟健管师加上企微；当天下午飞回深圳 |
| **Touchpoints** | 小程序（付款、开通、授权）、门店线下（若同行）、企微单聊（加健管师）、电话 |
| **Thoughts** | "总算安排上了""这个健管师看着挺靠谱""希望我妈能坚持戴" |
| **Emotion** | 🙂 → 😌 短暂的安心峰值（**这是她付费的那一刻买到的东西**） |
| **Pain points** | ① 现有流程里她**没有官方身份**——是付款人但不是系统角色，拿不到结构化信息；现状是直接微信转账给健管师，无合同意识；② 授权粒度需要老人单独同意，但"老人愿不愿让女儿看到夜间低血糖和漏测"这件事没人问过；③ 她当天就走，之后 17 天与门店的连接只剩企微 |
| **必须的产品动作（安全硬约束）** | **本地可到场施救者是入组必填项**。Level 3 低血糖的处置窗口以分钟计——一个在深圳的女儿收到推送后打电话回柳州，如果老人已经叫不醒，**这条链路就是空的**。缺失本地联系人则不允许开通夜间告警服务（否则我们在售卖一个不存在的兜底） |
| **必做的一次科普（临床评审修正）** | 原稿写"高血糖不是急症，低血糖才是"——**这句话会教会她忽略 euDKA 的唯一可观测入口**（她母亲在用达格列净）。<br>→ 正确表述：**"低血糖是分钟级急症；高血糖多数不是急症，但伴呕吐、腹痛、嗜睡、深大呼吸时是急症，必须立即就医——即使血糖不高。"** 后半句与健管师红旗清单一致 |
| **⚠ 收款迁移：本项目对门店最痛的一条变更（运营评审补入）** | 现状是她**直接微信转账给健管师**。迁到对公小程序收款涉及税、发票、健管师失去资金经手、店长失去现金流可见性。<br>→ **阻力大于"店长退群"**，而原稿只写了后者。必须作为独立的组织变更项排期，且**不能等到第一笔纠纷才做** |
| **⚠ 载体交付（前提变更后新增）** | 她付的这笔钱里现在包含一个**家庭蓝牙网关**（她母亲床头那个插着电的小盒子）。<br>→ 子女端必须能看到**网关在线状态**——因为"网关离线"直接等价于"今晚没有夜间兜底"，而这正是她付费买的那件事。<br>→ 若她母亲家没有 WiFi，密码往往在**她自己手机里**：S0 现场应直接电话联系她，而不是让老人转述 |

### 阶段 D3 · 头两周的日常（第 1–13 天）

> ⚠ **本段的时间线是 illustrative scenario（合成场景，非观测）。** "第 3 天痒、第 4 天夜里 2 点告警、第 8 天断数据"是一条连贯剧本，读者容易把它当成 typical case 来做资源分配——而 §4 的情绪曲线最低点正锚在"第 4 天夜里"。真实分布须由 §8-8 的家属访谈替换。

| 维度 | 内容 |
|---|---|
| **Actions** | 每天中午收到一条日报卡片，扫一眼；第 3 天母亲说"胳膊有点痒"她不知道要不要紧；**第 4 天夜里 2 点收到一次告警推送**——打电话，母亲没接；再打，接了说"我睡着呢，没事"；第二天她把通知静音了；第 8 天连续两天没有数据，她不知道是设备掉了还是母亲不测了 |
| **Touchpoints** | 企微/微信（日报卡片，静默通道）、小程序（子女端详情页）、**电话（告警，独立通道 + 必须回执）**、企微单聊（问健管师） |
| **Thoughts** | "还行，今天挺好"（连续 20 天之后：划走）<br>半夜："出事了吗？她怎么不接电话？我现在能干什么？"<br>"没消息到底是没事还是设备掉了" |
| **Emotion** | 🙂 平稳 → **😱 第 4 天夜里为全旅程情绪最低点** → 😑 静音后的麻木 |
| **Pain points（最密集）** | ① **她焦虑无处安放**：要么被报警轰炸（半夜手机响、发现是误报），要么完全没消息（不知道是没事还是设备掉了）；② **她在物理上救不了人**——收到推送后她能做的只有打电话，而这正是最没用的动作；③ 一旦被误报吵醒两次她就静音，**之后所有真报警对她失效**（P2 同时杀死老人端和子女端两个端）；④ 日报自身也会制造告警疲劳：连续 30 天"妈妈今天挺好"之后，第 31 天的异常也会被划走；⑤ 数据不足时若卡片写"平稳"，就是在**系统性地生成虚假安全感** |
| **必须的产品动作** | ① **日报与告警在通道、样式、声音上完全区分**：日报 = 静默、不进锁屏、可批量回看；告警 = 独立通道、必须回执；且做"只在有变化时加重"的设计。<br>② **只有 Level 2（<3.0 持续 ≥15 min）才允许夜间穿透勿扰**；Level 1 与设备类并入次日日报。<br>③ **静音不可静默失效**：她一旦事实上不再响应，系统必须在子女端和健管师队列同时标记"该家属已失联，**兜底责任回到值班人**"。<br>⚠ **但"她关闭了通知"这个事件技术上拿不到**（OS 级设置，微信生态不开放）。已改为**行为代理信号**：告警发出后 N 分钟内无回执 + 无卡片打开 + 无接听，**连续 ≥2 次**即判定失联。真正的兜底走**不依赖推送的电话通道**。<br>④ **回执超时（10 分钟无人确认）自动升级**到第二位家属再到值班健管师，不允许告警落地无人。<br>⑤ **推送文案要写"救援状态"而不是"血糖数值"**：「已通知本地联系人 X，健管师已联系上您母亲」/「已呼叫 120」——**让她知道救援在路上，而不是让她去决策**。<br>⑥ **没有数据 ≠ 平安**：传感器脱落、佩戴到期、连续 24 h 无数据要单独提示（"妈妈的传感器可能掉了，健管师已联系"） |
| **⚠ 数据来源必须标注** | CGM **不测睡眠也不测血压**。血压、睡眠属另行采集的数据源（家用血压计上报或健管师随访录入），**不得由血糖曲线推断**；日报须标明每项数据的来源与采集时间 |
| **⚠ 告警链路的三处跨文档修正（临床评审）** | ① **"Level 1 与设备类并入次日日报"必须拆开**：夜间传感器脱落 / 网关离线 / 连续无数据 = **整夜无监测**，对胰岛素使用者应**当夜通知本地联系人与值班人**，不能等次日。本文档自己写了"没有数据 ≠ 平安"，但通道设计把它降级了。<br>② **Level 1 是否推子女端，本文与 journey 01 原本规定不一致**——统一以本文为准：**Level 1 不推子女端**（并入次日日报），但在 journey 01 中，对**胰岛素/磺脲使用者或 IAH 高危者，Level 1 在老人端保留并把阈值上调至 4.4**。降噪的对象是子女端的打扰，不是患者本人的提前量。<br>③ **周报样例"周三夜里 2 点血糖降到 3.2"属 Level 1**，与"Level 1 并入次日日报"自相矛盾。已改为 Level 2 事件样例（见 D4） |
| **⚠ 载体离线是新的"静默失败"（前提变更后新增）** | 网关离线时，她的日报若照常写"妈妈今天挺好"，就是**系统性地生成虚假安全感，而且账还在付**。<br>→ 子女端必须有一个**始终可见的载体状态**，且离线 ≥2 h 主动推送："妈妈家的采集盒可能断电了，今晚暂时没有夜间监测，小韦正在联系。" |

### 她愿意继续付费的周报长什么样（本旅程的核心可交付物）

> 判据：**她要的不是数据，是"我今天要不要做点什么"的答案，加上"我花的钱买到了什么"的证据。**

| 模块 | 内容 | 反面（当前会犯的错） |
|---|---|---|
| **1. 一句话结论** | "妈妈这周血糖比较稳，**没有低血糖**；传感器工作正常。" | "TIR 58%，未达标" |
| **2. 一件她能感知的具体事** | "周三夜里 2 点血糖降到 **2.9（Level 2）**，系统立即呼叫并通知了张叔（本地联系人），小韦 3 分钟内联系上妈妈，补了葡萄糖片，15 分钟后**指血复测**回升到 4.6，已闭环。" | 一条曲线图；或用 3.2（Level 1）做样例——那与"Level 1 并入次日日报"自相矛盾 |
| **3. 一件"我们替你做了什么"** | "本周小韦跟她通了 2 次电话，换了一次敷贴（她胳膊有点痒），并已把用药问题转给黄医生。" | 无（现状：她完全看不见服务发生过） |
| **4. 一个她能做的动作（≤1 个）** | "这周给她打电话时，可以问一句：'妈，你一天喝几杯水？'" | 一份饮食建议清单 |
| **5. 数据可信度声明** | "本周有效数据 82%（周六回老家那天数据不全）。" | 数据不足时写"平稳"或留空 |
| **6. 医学指标** | 放在"查看详情"二级页，并配人话解释。⚠ **7 天窗口只出趋势描述，不出达标判断**——达标判断只在 14 天 + ≥70% 有效数据窗口给出（R01）。周报是最高频的触点，若在这里给达标判断，数据充分性门槛会被系统性绕过 | "TIR 68%，目标 70%，未达标"（双错：既绕过门槛，又用了成人标准） |
| **6b. 老年基准（出结论时才写）** | 满足门槛时才写："过去 14 天有 68% 的时间血糖在理想范围内。**对 68 岁、病程 20 年、在用胰岛素的老人，目标是 50% 以上，妈妈是达标的**" | 用成人 70% 做基准——会让她要求加强控制，而她母亲真正的风险是**降得太狠** |
| **7. 排除项** | **不含**原始诊疗记录、用药明细、分型/疗效结论。用药相关一律标注"已转黄医生，医师意见将由门店告知" | AI 直接回答"要不要加药" |

**老年目标必须写进周报**：用成人 TIR>70% 去评价刘阿姨，会让李女士得出"我妈很糟糕"的错误结论，进而要求加强控制——**而她母亲真正的风险是降得太狠**。周报里的"好"必须定义为"稳、不低"，不是"降"。

### 阶段 D5 · 续不续（第 18–90 天）

| 维度 | 内容 |
|---|---|
| **Actions** | A→B 的升级决策（第 17 天前后）；若升 B 包，则在第 30/60/90 天面对月度续费节点；某个月手头紧，或母亲说"别浪费钱了"，她进了续费页却没付；30 天后彻底失联 |
| **Touchpoints** | 小程序（续费页）、企微单聊（健管师）、电话（母亲） |
| **Thoughts** | "这个月手头紧""我妈自己也说不用弄了""一个月一千块，值不值" |
| **Emotion** | 😐 → 😔（若无降档选项则直接退出） |
| **Pain points（P5 费用脱落）** | ① 非胰岛素 T2D 12 个月持续使用率 46.5%，**停用首因就是费用，占 46%**；② **老人说"别浪费钱"经常是给子女的台阶**，不是真实意愿——她会顺着这句话退出，并把责任归给母亲；③ 门店现状：无续费预警、无降档选项，只有"续/不续"二选一，停付后即失联；④ 停用后 TIR 由 77% 回落至 60%——**一旦退回指血仪就基本回不来了** |
| **必须的产品动作** | ① **必须有降档，不能只有退出**：B 包续约维持包（每 3 个月 1 枚 CGM + 1 次 HbA1c + 医师 1 次，680–980 元）做成**默认挽留选项**，在续费页与流失预警里同时出现。<br>② **续费预警推给她，不推给老人**（老人端不显示任何价格）。<br>③ **续费前 7 天推送"这 90 天你妈妈的变化"**：低血糖事件次数下降、告警响应时延、体重稳定率、我们联系了多少次——**把"我花了什么"换成"我得到了什么"**。≥65 岁**不得使用减重指标**。<br>④ **CGM 间歇使用**（首月连续、之后月度复查）是成本对策，把 CGM 占售价压到 10–13%。<br>⚠ **但它有禁忌（临床评审补入）**：**已确认无感知低血糖（IAH），或 14 天内出现 ≥1 次 Level 2 事件 / TBR(<3.9) ≥1% 者，不得降为间歇监测**——对刘阿姨这类人，间歇使用恰好会漏掉这个服务唯一真正的临床价值。<br>⑤ ~~**停付不等于停服**：设 30 天"静默维持期"~~ → **降级为"待法务与门店确认后方可实施"**（UX 评审）。未告知的持续监测 + 责任真空：用户以为已停服，系统仍在监测但没人承诺响应；这 30 天里一旦出事，法律与舆情风险极大。<br>→ 若要做，**必须是显式、可拒绝的告知**："您已停止付费。我们将在接下来 30 天继续保留低血糖告警（由 X 负责响应），如不需要请回复取消。" **一个挽留手段包装成关怀、而用户从未同意——这正是 D1 里她担心的'套路'。**<br>⑥ 支持 2–3 个家属账号，通知同时到达，**"谁已联系上老人"的状态共享**，避免重复打电话和互相推诿。<br>⑦ **伦理护栏（UX 评审必改）**：**老人本人明确表示要停时必须停并记录，不得只与子女沟通。** 挽留可以做，但必须同时告知老人本人 |

```
    ·          ·   ·                                ·          ·
    ·        ·      ·                             ·             ·
中  ·  ·····         ·······  ·······  ·······  ·                ······  D5a（续费/降档）

    ·                                                                   ·

低  ·                    ▼                            ▼
    ·              D3 第 4 天夜里                  D4b 只收到 PDF
    ·              （告警 + 打不通 + 我什么都做不了）
    ├────────┼────────┼────────┼────────┼────────┼────────┤
      D0 发现   D1 查比   D2 付钱   D3 头两周  D4 结营   D5 续不续
      −14~−7   −7~−1     第 0 天   第 1–13   第 14–17  第 18–90
```

**读法（三条判断）**

1. **最低点在 D3 的第 4 天夜里**，不在停付时。那一刻她同时经历三件事：被吵醒、打不通电话、**意识到自己在物理上什么都做不了**。这一刻决定了她之后是"继续信任系统"还是"把通知静音"——**而静音之后，她买的东西已经失效了，只是账还在付**。
2. **D2 的安心峰值是她付钱那一刻买到的全部东西**，此后 13 天系统必须持续兑现它。她的付费不是一次交易，是**一个需要每天续证的承诺**。
3. **D4 和 D5 的分叉都不由母亲的病情决定**，由我们有没有让她"看见服务发生过"决定。这是运营变量，不是临床变量。

## 9. 关键洞察

1. **她买的不是数据，是"有人替我看着"。** 付费发生在 D2 那一刻的安心感，但那笔钱要靠之后 13 天每天续证。因此产品最重要的输出不是 AGP，是**周报模块 3「我们替你做了什么」**——把健管师那些不可见的人工劳动（通了 2 次电话、换了一次敷贴、转了一次医师）变成可计价的证据。**服务发生了但她看不见，等于没发生。**

2. **她是知情方，不是施救方——把这条写进架构，不只是写进文案。** 一个在深圳的女儿收到"母亲低血糖"推送后能做的唯一动作是打电话，而这恰恰是最没用的。所以：**本地可到场施救者必须是入组必填项，缺失则不允许开通夜间告警服务**——否则我们是在售卖一个不存在的兜底。给她的推送要写"救援状态"（已通知 X / 已呼 120 / 已处置闭环），不要写血糖数值。

3. **静音是她"事实上退出"的时刻，而不是停付。** 停付发生在第 30–90 天，静音可能发生在第 4 天。静音之后她还在付钱，但她买的东西已经失效了。**因此"关闭通知"必须是一个红档可观测事件**，且必须立刻把兜底责任显式转移给值班人——否则我们会有一批账面上活跃、实际上已经没有任何人在看着老人的客户。

4. **老人的"别浪费钱了"可能是给子女的台阶——但这是一个假设，不是洞察。**
   ⚠ **UX 评审的最重要一条**：原稿据此设计了"把续费决策拉回她与健管师之间，**不经老人转述**"，这在伦理上是**绕过服务对象本人**的挽留话术，正好落在保健品行业最受诟病的那条线上。**这是全文唯一一处商业动机盖过了用户自主权，而它被写成了"洞察"。**
   → **待验证**：对说过这句话的老人做 10 次单独电话回访（不经子女），问"如果钱不是问题，你还想不想继续戴"。
   → **无论真假，伦理护栏先行**：老人本人明确表示要停时**必须停并记录**；挽留可以做，但必须同时告知老人本人。
   → 站得住的那半条仍然成立：**默认给降档（维持包 680–980 元）而不是"续/不续"二选一**——停用首因是费用（46%），而一旦退回指血仪，TIR 从 77% 掉到 60%，就基本回不来了。

5. **用成人标准评价她母亲，会诱导她要求做错的事。** 如果周报写"TIR 58%，未达标（目标 70%）"，她的反应会是"加强控制"；而刘阿姨的真实风险是**降得太狠**（20 年病程 + 胰岛素 + HbA1c 7.4%，老年目标 7.5–8.0%）。周报里的"好"必须定义为**稳、不低**，不是降。**这既是临床正确，也恰好是她真正想买的东西——她怕的是母亲出事，不是母亲指标不漂亮。**

6. **她的付费理由刚刚升级了一档，而兑现门槛也跟着抬高了一档。** 硅基接入打通前，"夜里出事第一时间通知你"在物理上做不到，只能卖"每天一条安心报告"。现在它是可交付承诺，**这是打通接入带来的唯一新增付费理由，也是最值钱的那个**——但它把一个技术限制换成了一条合同义务：承诺什么就必须监控什么。**她母亲床头那个网关有没有插着电，从此和这笔钱直接挂钩。** 因此子女端必须始终可见载体状态，且**绝不允许在离线时照常写"今天挺好"**。

7. **"逆转"这个词在她身上是负资产。** 门店最引以为豪的招牌，对这个人群的第一反应是搜"骗局"；而堆砌资质与专家背书的 WTP 只有 17.6–18.5 元。**唯一有效的价值主张是讲清楚"我们替你做什么"**——这也正好是那 46 个百分点（自助 42.7% vs 人工支持 89–92%）的商业化表达。
