# Persona 07 · 王叔 — 脱落 / 退款型用户（反向画像）

> glycowise / persona-insight · 2026-09-04
> 依据：`sources/03` §6.1 §6.2 §4.3 §4.2、报告 §4.2（服务包 KPI）、`sources/00`（门店现有应对流程）
> 评审：diabetes-cgm-expert、elderly-nutrition-expert、ux-researcher（Step 4 意见已并入）

## 这份画像的写法声明

**王叔不是"意志力薄弱的用户"，他是我们产品缺陷的镜像。** 他的每一个退出动作都精确对应设计里的一个具体漏洞：他在第 4 天摘掉传感器，是因为我们没在第 2 天问他痒不痒；他在第 14 天不续费，是因为我们给了他一份他看不懂的 PDF 而不是一次面对面解读。

把脱落归因于用户，是这个行业最贵的自我安慰——**CGM 业务的真实死因是脱落，不是获客**：健康人群真实世界只有 42.7% 完成一个佩戴周期，非胰岛素 T2D 12 个月持续使用率 46.5%。前面 6 个 persona 描述的是"如果一切顺利"，王叔描述的是"实际会发生什么"。**他不是第 7 类用户，他是前 6 类用户在第 3 天到第 6 个月之间的另一种结局。**

## 六条退出路径

### P1 · 皮肤脱落（第 3–5 天）

| | |
|---|---|
| **触发时点** | 佩戴后第 2 天开始痒，第 3–4 天出现红疹/渗液，第 4–5 天摘除。文献：皮肤问题 45%、疼痛 43%，**4–18% 因皮疹停用** |
| **真实心理** | "是不是过敏了？会不会烂？"——不是嫌麻烦，是**怕出事**。这是一种健康焦虑，不是依从性问题 |
| **他会对谁说什么** | 先对老伴说"这东西弄得我痒"；群里**不说**（怕被说娇气，也怕健管师劝他坚持）；健管师问起时说"还行"。**他摘掉后仍然不说** |
| **门店应对现状** | 无。佩戴时不做皮肤保护教学，佩戴后无主动回访；群里也没人问过"痒不痒"。健管师通常在第 7 天数据断了才发现 |
| **我们本可以在哪拦住他** | ① **佩戴当天（第 0 天）**：SOP 增加"先贴皮肤保护膜/隔离敷料再贴传感器"，并现场演示部位轮换与防水贴洗澡（**明确禁止保鲜膜包裹**——会造成胶布松脱与皮肤浸渍）。② **第 2 天 + 第 4 天两次定向推送**，只问一个是非题："贴的地方痒不痒？"（是/否两个大按钮），选"是"直接进健管师队列的橙色档。③ **社群应答智能体做关键词监听**：群内文本/语音转写命中"痒、红、疼、起疹、过敏、贴不住"即自动建工单。④ 备好**替换敷贴与部位轮换方案**，让"换一个地方贴"成为默认动作，而不是"摘掉"。⑤ 建立**传感器不良事件记录与上报路径**（器械合规要求，见 persona 06）|

> **这是六条里最早、最便宜、最可拦的一条**，也是最不该发生的一条：81.9% 报告不适的人**愿意继续**——只要有人处理。

### P2 · 告警疲劳脱落（第 2–7 天）

| | |
|---|---|
| **触发时点** | 夜间侧卧压迫伪差 → 假性低血糖告警 → 连续 2–3 晚被吵醒 → 关闭通知（第 3–5 天）→ 摘除（第 5–7 天）。**关通知和摘设备之间有 2–4 天的可挽救窗口** |
| **真实心理** | "又不是真的低，白吓一跳"→"睡不好比血糖高更难受"→ 对系统的信任崩塌。**误报一次的代价不是一次打扰，是之后所有真报警的失效** |
| **他会对谁说什么** | 对子女抱怨"半夜老叫"（子女随即也把通知静音——**一次误报同时杀死两个端**）；群里可能说一句"昨晚又响了"，被当成闲聊划过 |
| **门店应对现状** | 无告警分级、无去抖、无夜间值班。夜里的告警发进企微群，没人看；第二天也没人回溯"昨晚为什么响" |
| **我们本可以在哪拦住他** | ① **去抖是硬要求**：低于阈值**持续 ≥15 分钟**才算事件，单点低值一律不告警（压迫伪差在夜间侧卧时常见）。② **老人端只保留 Level 2**：Level 1 与预测性告警在老人端静音、并入次日日报；**Level 2（<3.0）不可静音、不可关闭**（见 persona 01——静音 Level 2 会剥夺自救窗口）。③ **"关闭通知"必须是一个可观测事件**：客户端上报后立即进健管师队列，并在子女端标注"该家属已静音，兜底责任回到值班人"。④ **每次告警后 24 小时内做一次归因回访**："昨晚那次是压着了还是真的低？"——把误报转成一次关怀触点而不是一次伤害。⑤ 佩戴时教**避开惯用侧卧位**的部位选择 |

### P3 · 数据打击脱落（第 5–10 天）

| | |
|---|---|
| **触发时点** | 第 3–5 天开始每天看到大片红色/超标标记 → 第 5–7 天出现回避行为（不开日报、不扫描）→ 第 7–10 天停止一切互动。文献明确把"**监测焦虑**"列为老年 CGM 障碍之一 |
| **真实心理** | "我这么努力了还是全红"→ 无力感 → "不看就不难受"。**这是习得性无助，不是懒**。对刘阿姨型用户还叠加一层："是不是我快不行了" |
| **他会对谁说什么** | **什么都不说**。这是最沉默的一条路径，也因此最难靠人工发现——只能靠数据先兆 |
| **门店应对现状** | 日报模板是"结论式 + 问题导向"（今天超标 X 次、TIR 未达标），没有任何正向反馈；健管师的沟通也以"哪里不好"为主 |
| **我们本可以在哪拦住他** | ① **日报必须有一条"你做对了什么"**：即使是"昨晚 11 点到早 6 点全程平稳"这种小事，也要写出来——**每日卡片正向:负向内容比例不得低于 1:1**，这是可校验的模板规则。② **前 3 天不给任何达标/未达标判断**，只做适应期描述（临床上也站得住：14 天 + 70% 才是结论门槛）。③ **红色不铺满屏**：老人端不呈现原始曲线，只给"一个颜色 + 一句话 + 一条行动"；TIR/GMI/超标次数不进主界面。④ **把"波动"翻译成可控变量**："昨天中午那碗粉之后升得比较快，今天试试先吃菜"——给他能动的把手，而不是一个他动不了的分数。⑤ 监测焦虑筛查：连续 3 天回避行为即触发健管师电话，而不是发更多消息 |

### P4 · 价值落差脱落（第 14–17 天）

| | |
|---|---|
| **触发时点** | 14 天佩戴结束 → 收到/自取一份 AGP 报告 → 未到店解读 → 第 15–17 天婉拒续费。**这是 A 包 → B/C 包转化率 ≥30% 这个 KPI 的死亡点** |
| **真实心理** | "花了 399，结论就是'我血糖高'？这我做体检就知道了。" ——他买的是**答案**，我们给的是**数据**。这是价值主张的失败，不是他不识货 |
| **他会对谁说什么** | 对子女："别弄了，没啥用。"对健管师："我再考虑考虑。"（**这句话是已经决定了**）群里：不说。这条路径**不产生差评，但产生最大的商业损失** |
| **门店应对现状** | 报告靠导出 PDF 发群里；结营解读到店率无人统计；第 20 天左右做一次回访电话——**已经晚了 6 天**，他早决定了 |
| **我们本可以在哪拦住他** | ① **结营解读到店是服务包的交付条款，不是可选环节**：预约在第 12 天就锁定（佩戴还没结束时就约好），到店率作为健管师 KPI（报告已列 ≥70%）。② **报告要有"三个发现 + 三个动作"的人话首页**，AGP 图放在第二页之后；PDF 不是交付物，**面对面的 30 分钟才是**。③ **第 7 天插入一次"中期小结"**，提前兑现一部分价值，不要把所有价值都押在第 14 天——他在第 7 天就已经在判断"这钱花得值不值"。④ **价值锚点要从"知道血糖高"移到"知道哪顿饭、哪个时段、下一步做什么"**：至少给出 1 条经 ≥2–3 次重复验证的个体化餐后发现（临床门槛见 persona 02）。⑤ 对糖前期/健康人群**入组时就不承诺血糖获益**（ADA 2026 证据等级 C），把承诺锚在减重与行为洞察上——**期待管理做在售前，比在第 15 天挽留便宜十倍** |

### P5 · 费用脱落（第 30–90 天）

| | |
|---|---|
| **触发时点** | 月度续费节点、或子女端一次未完成的支付。文献：非胰岛素 T2D **停用首因就是费用，占 46%**；价格相对重要性 62.7% |
| **真实心理** | 老人侧："一个月几百块贴个东西，够买多少斤肉。" 子女侧："我这个月手头紧""老人自己也说不用弄了"——**子女的退出常常借老人的口说出来** |
| **他会对谁说什么** | 老人对子女说"别浪费钱"（**这句话经常是给子女的台阶**，不是真实意愿）；子女对健管师说"我们先停一停" |
| **门店应对现状** | 无续费预警、无降档选项，只有"续/不续"二选一；停付后即失联 |
| **我们本可以在哪拦住他** | ① **必须有降档而不是只有退出**：B 包续约维持包（每 3 个月 1 枚 CGM + 1 次 HbA1c + 医师 1 次，680–980 元）要做成**默认挽留选项**，在续费页与流失预警里同时出现。② **续费决策发生在子女端**，所以流失预警要推给子女而不是老人（老人端不显示价格——见 persona 01/03）。③ **续费前 7 天推送"这 90 天你的变化"**（TIR、低血糖事件下降、体重稳定率——≥65 岁不用减重指标），把"我花了什么"换成"我得到了什么"。④ **CGM 间歇使用**（首月连续、之后月度复查）本身就是成本对策，把 CGM 占售价压到 10–13%。⑤ **停付不等于停服**：设 30 天"静默维持期"，保留低血糖告警与月度关怀——**流失后 30 天内是唯一还能召回的窗口**，一旦回到指血仪（TIR 由 77% 回落至 60%）就很难再回来 |

### P6 · 承诺落空退款（第 180 天）

| | |
|---|---|
| **触发时点** | 缓解包 180 天结束，未达"缓解标准或减重 ≥10%"任一。报告推算承诺触发率 ≤35%，**意味着每 3 个缓解包客户就有 1 个走到这一步** |
| **真实心理** | "你们承诺过的。"——他记住的是销售当时的口头表述，不是合同条款。**如果销售话术里出现过"逆转""治愈""能停药"，他记住的一定是那个版本** |
| **他会对谁说什么** | 到门店当面要说法；大众点评/小红书；亲戚饭桌。**这是六条里唯一会造成外部声誉损害与合规风险的路径**——一旦他在投诉里引用门店的"逆转"话术，同时触发医疗广告与固体饮料两条红线 |
| **门店应对现状** | 无标准化的争议处理流程；"糖尿病逆转中心"的招牌和朋友圈案例本身就在制造这个预期 |
| **我们本可以在哪拦住他** | ① **入组即做期待管理，并留痕**：缓解包必须先完成 ABCD 筛查（抗体阴性、空腹 C 肽 ≥1.1 ng/ml、病程 ≤5 年、BMI≥25 或腰围男>90/女>85）；**不符合者不得售卖缓解包**——卖给不可能缓解的人，退款是必然结局而不是风险。② **签署时用书面 + 口头双确认**说明证据边界：DiRECT 2 年缓解 36%、**5 年降至 13%**；缓解定义是停药 ≥3 个月 HbA1c<6.5%，**不是"治愈"、不是"逆转"**。③ **承诺条款以"赠 3 个月维持期"而非现金退款**兑现，并在合同中写明触发条件与举证口径；按 5% 计提准备金。④ **全渠道禁用"逆转/治愈/停药"**（门店招牌、物料、企微名片、朋友圈、AI 输出），门诊名称整改到位——**这条不是合规成本，是 P6 的根因治理**。⑤ **第 90 天做一次中期兑现评估**：若已明显偏离缓解路径，由医师主动沟通改走维持方案并调整承诺，**不要等到第 180 天才让他发现**。⑥ 结营材料只出聚合数据、按用途分流（对外需医疗广告审查证明，见 persona 06）|

### 三条实现约束

1. **信号必须区分"他退出了"和"他外出了"**：外出模式（persona 01/04）开启期间，S3/S7/S8/S9 暂停计分，只保留 S1/S4/S5。否则系统会把正常生活误判成流失，健管师被无效工单淹没，最后关掉整个挽留功能。
2. **挽留工单与临床告警必须分链路、分队列、分优先级**。临床红旗（Level 3 低血糖、疑似急性代谢危象）永远在第 0 层，挽留工单最高只能进第 1 层。**绝不允许商业挽留占用临床响应资源。**
3. **考核口径要防"为留存而留存"**：挽留率不得成为独立 KPI，否则健管师会去做无效催促，反而加速 P3。正确口径是与"佩戴有效数据率 + 结营到店率 + 降档续约率"绑定。

## 设计启示

1. **把"第 2 天问一句痒不痒"当成一个正式的产品功能，而不是服务态度**。P1 是六条路径里最早、最便宜、最可拦的一条，且文献明确 **81.9% 报告不适的人愿意继续——只要有人处理**。第 0 天的皮肤保护教学 + 第 2/4 天的是非题推送 + 关键词监听 + 替换敷贴常备，这套组合的总成本低于一枚传感器，却能保住 14 天 + 70% 这个所有临床结论的前置门槛。**门槛没保住，后面全部功能归零。**

2. **每一次误报都要有一次归因回访，把伤害转成触点**。告警的价值不在覆盖率，在可信度。去抖（≥15 分钟）+ 老人端只留 Level 2 + "关闭通知"作为可观测事件上报 + 次日归因回访——这四件缺一不可。**注意 Level 2 不可静音**（persona 01 已修正）：降噪的对象永远是 Level 1 和预测性告警，不是救命的那一档。

3. **日报的正负内容比不得低于 1:1，前 3 天不给判断**。P3 是最沉默、最难发现的路径，唯一的解药是让他每天都看到一件"我做对了的事"。这既是留存设计，也有临床依据：14 天 + 70% 才是出结论的门槛，**前 3 天本来就不该给达标判断**。红色不铺满屏，把"波动"翻译成他能动的把手。

4. **结营解读到店是交付条款，第 12 天就锁定预约**。P4 是唯一 100% 由我们控制、且一旦失守前面所有努力归零的节点——它直接决定 A→B/C 转化率 ≥30% 这个 KPI。PDF 不是交付物，面对面的 30 分钟才是；第 7 天要有中期小结提前兑现价值；报告首页是"三个发现 + 三个动作"，AGP 图往后放。

5. **给降档，不要只给"续/不续"**。停用首因是费用（46%），而费用决策发生在子女端。维持包（680–980 元）要做成流失预警里的默认挽留选项；续费前 7 天推送"这 90 天你的变化"；停付后设 30 天静默维持期保留低血糖告警——**流失后 30 天内是唯一的召回窗口**，一旦退回指血仪（TIR 77%→60%）就基本回不来了。

6. **P6 的根因治理在售前，不在售后**：不符合 ABCD 筛查的人**不卖缓解包**；书面 + 口头双确认证据边界（DiRECT 5 年缓解率降至 13%）；全渠道禁用"逆转/治愈/停药"；第 90 天中期兑现评估主动改走维持方案。**卖给不可能缓解的人，退款是必然结局而不是风险**——而这条路径同时带外部声誉损害与医疗广告/固体饮料双重合规风险。

7. **把"人工支持"当作产品的第一功能，而不是成本项**。自助场景 42.7% vs 人工支持场景 89–92%，这 46 个百分点就是我们全部的产品空间与定价依据。所有 AI 能力的设计目标都应该是**让健管师能在正确的时点出现在正确的人面前**，而不是替代那次出现。

## 待确认（用户不在线，Step 5 Validate 未执行）

- **【最值得先验证】六条路径的真实占比与时点分布。** 本画像的路径构成是从文献 + 门店定性反馈合成的，**门店当前没有任何流失记录**（既不记录摘除时点，也不记录未续费原因）。最便宜的验证：从下一批入组起做**强制退出访谈**——任何人佩戴中断或不续费，健管师必须完成一份 5 题问卷（哪天停的 / 因为什么 / 当时最难受的是什么 / 有没有告诉过我们 / 什么情况下你会回来）。零开发，一个月就能拿到真实分布，并据此重排上面六条的优先级。
- 皮肤不良事件在柳州气候（湿热多汗）下的实际发生率——文献 45% 是国外数据，本地可能更高，直接影响 P1 的权重与敷贴选型。
- S1–S12 各阈值均为**首版推算值**，需用首批 20–30 人的真实数据回校（尤其 S7 的"5 天"、S8 的"12 小时"、S3 的"15 pp"）。上线前应先以"只记录不触发"模式跑 2 周，看误报率。
- 群内关键词监听（S1/S11）涉及对患者对话内容的自动分析，**PIPL 上需要单独同意**，且与"血糖触发产品推荐要再单独同意"是同类问题。需法务确认告知口径。
- 门店是否愿意接受"挽留率不作为独立 KPI"这一约束（与 persona 06 的月度考核逻辑冲突）。
- P5 的"静默维持期"是否可行：涉及停付后仍提供低血糖告警的责任边界与成本，需与至心/德心确认。
- 大众点评/小红书的负面内容监测是否要纳入产品范围，还是留在门店运营侧。
