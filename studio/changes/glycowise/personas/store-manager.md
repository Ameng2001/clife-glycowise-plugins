# Persona 06 · 覃店长 — 门店店长 / 区中心站长（增补 persona）

> glycowise / persona-insight · 2026-09-04
> 增补理由：本项目的三条硬约束（CGM 不碰货、产品与服务分离、AI 不出处方）**每一条都直接削减门店当期营收**，
> 而执行这些整改的人是店长。他不是产品的使用者，却是产品能否上线的**否决者**。
> 依据：`sources/00`（店长在患者企微群内）、报告 §2.2 §3.4 §5、`sources/03` §5.4 §6.3

## 设计启示

1. **先给桥，再拆引擎**：任何要求"停用分级→产品表"的整改必须与"可售服务包 + 可见续费率"同时上线，否则他会在执行层面消极抵抗（改话术不改行为），产品的合规闸门被绕过。产品排期上，服务包售卖与续费看板不能排在合规整改之后。
2. **给他一个经营看板，但与临床台隔离**：他能看营收、续费率、佩戴依从率、健管师产能、渠道分佣，**不能看**个体患者的血糖与用药明细。这一条同时解决"店长退出患者群"的组织阻力——退群不等于失去可见性，聚合看板替代之（**但见"待确认"第一条：这个替代关系本身是待验证的假设，须先用纸质报表 + 3 个群退群试点验证**）。
3. **把合规做成可举证的资产——但"聚合"不是万能出口**（临床专家 + 营养专家双重评审必改）：
   - **按用途分两类，权限不同**：**(a) 对内/对总部/对专业渠道的经营与质量分析**——可含 TIR 改善分布、体重变化、样本量与口径说明，标注"内部质量改进用途，不得用于对外宣传"；**(b) 对外任何面向患者或不特定对象的材料**——不得出现疗效数字、治愈率、有效率、前后对比。**去标识化解决的是 PIPL，解决不了广告合规**：对不特定对象宣传医疗服务的疗效数据仍属医疗广告，需医疗广告审查证明，《医疗广告管理办法》第 7 条禁止以疗效或治愈率作宣传，聚合过的"TIR 改善 XX%"照样踩线。系统在导出时按用途分流并自动加水印与合规尾注。
   - **"减药率"一律不得作为门店或个人的考核与展示指标**：用药加减停是医师的个体化临床决定，把它变成 KPI 就是在用商业激励撬动处方行为，风险等级高于固体饮料话术。可替换为"医师评估完成率""随访依从率"这类过程指标。
   - **≥65 岁组不得使用减重作为成效指标**：老人的体重下降更可能是肌少症、营养不良或疾病进展，而这套 KPI 会激励整店去追求它——这是唯一一条会**从组织激励层面批量伤害老人**的设计。分年龄段出数据：<65 岁组用「TIR 改善分布、平均减重、腰围变化」；≥65 岁组改用「TIR 改善、低血糖事件下降、体重稳定率（波动 <±3% 的人数占比）、骨骼肌量维持率、营养风险筛查阳性转阴数」。同一份材料须标注："本服务对老年人群的目标是血糖平稳与营养维持，不以减重为目标。"——**老人掉秤在这套服务里是不良事件，不是业绩。**
   - 系统层面禁止导出个案前后对比图用于营销。
4. **AI 的 ROI 要说给他听**：工作台需给出"本月 AI 替代手工录入 X 小时、健管师人均管理 Y 人、告警响应中位时延 Z 分钟"，这是他决定是否续订 SaaS 的唯一依据。产能指标（人均 ≥60 人）必须可测量、可回溯。
5. **"7 天试用"与"谁佩戴 CGM"两处必须对齐临床与器械边界**（临床专家评审必改）：
   - **试用期口径**：7 天数据不满足 14 天 + 70% 门槛，**不能出任何达标或分级结论**。体验包只输出"佩戴体验 + 曲线趋势描述 + 后续建议"，页面显式标注"数据周期不足 14 天，未达出具达标结论的门槛"；销售话术与物料同步调整，**不得承诺"试用出评估报告"**。
   - **佩戴执行主体**：CGM 属医疗器械，敷贴式传感器由无医疗资质的健管师"代为完成"存在边界问题。门店角色应为"**指导患者/家属自行佩戴**"——健管师现场教学、核对贴敷部位、确认信号正常并留影像记录，操作动作由患者或家属完成；话术、SOP 与合同措辞统一为"**佩戴指导服务**"，不得表述为"由门店为您植入/安装"。同时建立传感器不良事件（皮肤反应、脱落、断裂残留）的记录与向厂商/监测机构上报的路径。
6. **器械交易在系统里彻底不可达**：小程序商城不上架 CGM，门店角色无开单权限，收款链路物理不通向门店账户；引流按持证厂商/经销商结算并留痕。设计上不给他"变通"的接口，比写在制度里有效。
7. **SOP 可复制到 17 店**：把整改后的流程做成可配置模板（入组筛选 → 佩戴 → 授权 → 告警 → 签发 → 结营），新店开箱即用。这是他真正的动机——不是控糖，是可复制的门店模型。

8. **为"第一个月"设计，而不是为终态设计**（UX 评审补入）：他的决策窗口是月度——"影响这个月数字吗"是他对任何新流程的第一问。**任何整改方案必须能在上线 30 天内给出一个他可以拿去交差的数字**（服务包首单量、续费意向数、AI 替代工时）。缺少 30 天内可见正向指标的方案，无论长期多正确，都会在第二个月被他悄悄回滚。排期上须专门安排一个"30 天可交差指标"作为验收项。

## 待确认（用户不在线，Step 5 Validate 未执行）

- **【最值得先验证】"聚合看板可替代群内可见性"是假设而非结论。** 他在群里读的是转化时机与服务口碑等定性信号，与聚合指标不同质，很可能被他判定为降级并引发抵制。最便宜的验证：不做系统，先手工做 2 周——每周给他一份纸质聚合报表，同时请他退出 3 个患者群作为试点，2 周后访谈"这两周你有没有觉得看不见了、具体是哪件事"。这个试点还能顺带产出真实的看板字段需求。

- 英纽林产品在当前营收中的实际占比，以及分离后的营收缺口大小——这是整改能否推行的核心数字，`research/` 未覆盖。
- 至心与德心的关系与利益分配（德心卖产品、至心做服务，二者对合规整改的立场可能相反）。
- 店长与总部的考核口径：是否已有"服务收入占比"这一指标，若无需先推动总部改考核。
- 店长退出患者群的替代方案是否被组织接受（聚合看板 vs 群内可见）。
- 门诊名称整改（招牌、物料、企微名片）的成本与时间窗。
- 渠道分佣比例（A 包 10–15%、B/C 包 8–10%）为推算值，需与实际渠道谈判校准。
